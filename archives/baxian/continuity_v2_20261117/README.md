接续导演方案：{'MOTIVATED_EDIT_CUT': 112, 'BRIDGE_ACTION_REQUIRED': 12, 'TAIL_CONTINUATION_CONDITIONAL': 4}。此分类是根据镜头文本、动作阶段、法器状态制定的执行决策，尚未逐对获得实际视频/尾帧视觉证明。尾帧续生均附机位兼容条件，条件不成立必须改切镜或补动作。12个过渡风险点不等于12张已确认缺图，也不预先声明每处都需付费新增视频；先检查实际生成的前段是否已经覆盖缺口。

1. 开镜前核实际批准源、法器阶段、可见手足/支撑、尺度和光源，NEEDS_EVIDENCE必须取得证据才能放行。
2. 连续动作先生成前段，审正常速度、关键接触和前后关系，再抽取最后合格帧。登记真实帧号、PTS、SHA与母视频，不能随手截预览图冒充原尾帧。
3. 首尾帧一致不代表速度一致；比较切点前后0.5–1秒的动作相位、方向、速度、重心、风浪和镜头运动。光流只是参考，不能跨机位用全画面像素差阈值判错。
4. 同机位续段使用实际合格尾帧；需要动量时优先使用模型支持的前段视频延展/参考，静帧不能保存速度。下一批准图作造型/目标姿态约束，不能在构图不兼容时硬作首尾。
5. 过渡段沿已批准身份与场景补足动作，不预设2秒为模型支持档；按实际模型最短可用档生成后剪取，禁止全段变速凑时长。
6. 切镜允许机位改变，方向和因果必须成立；不把铜铃变成缆绳、不把室内门变成海底门、不把外海四王瞬移成近岸四王。水墙/云雾遮挡必须是既有动作有源造成，不能专为遮穿帮凭空爆雾。
7. 每个接点正常速度连看两遍，重点慢放接触/遮挡再现与切点；身份、器物、肢体、承重或剧情顺序错误即阻断该链。尾帧出现错误先修前段，不能让错误在后段遗传。
8. 音效分轨制作，保持场景有动机的声场变化。拒绝双人重影叠化与AI光流补帧掩盖缺失动作；8K超分在原生动作与接点通过后做。
