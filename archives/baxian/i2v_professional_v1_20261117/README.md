## 实拍质感与8K交付

统一古装真人电影观感：批准演员骨相、年龄、体型、服装层次不换；自然皮脂汗湿、细毛与唇纹随景别，粗布织纹/金属/玉/竹木有真实反射，禁止蜡脸、美颜、砂纸毛孔、游戏塑料与过锐HDR光晕。神话物种仍保留批准的角、鳞、膜翼与法器，不用真人皮肤规则抹掉龙的设定。史诗感由尺度参照、前中后景、浪根与碰撞、近舰船首甲板索具、光源层次和受力表现建立，不靠满屏光球与无差别拉远。

竖幅最终交付目标4320×7680、9:16；剪辑目标24fps。实际模型原生分辨率/帧率/档位必须在选模型后核接口并读生成文件，不写虚假的原生8K。当前约941×1672等尺寸首图不能凭“8K关键词”恢复不存在细节。先以模型最高实际可用原生规格生成并审动作，再做可追溯超分和必要稳纹理，最后独立审核；超分不等于新增真实毛孔。若支持且有实际编码证据，可交10-bit版本；否则不标HDR/10-bit。

画幅适配必须等比。历史7条任务引用6份旧图宽高比不符9:16；现已全部替换为批准941×1672修正版，04表保留原问题及解决记录。不得非等比拉伸、裁断头冠/手/脚/兵器或偷偷重绘已批图。先核安全裁切余量；无余量时保持原生构图、在合成画布做可说明的适配或另行批准派生背景扩展。此处适配已完成，不要求重画已批准全库。

## 不能倒演的动作

输入图是批准瞬间锚点，不保证每张都是案本起势。剑尖已接潮甲就延续裂点；已回鞘的剑不再拔出来演归还；人已落海只演余势；葫芦卡口从卡住继续收尽；灯已燃只演护手收势，不再自熄点一遍。前镜尾状态、本镜案本首尾与输入实际姿态分别列出，不用“从A变B”一句话掩盖错帧。

相邻镜默认是剪辑接力，不自动是同一机位的首尾帧。只有地平线、尺度、透视、角色位置、光源及法器状态在实际图像中兼容，经对照后才能使用首尾图控制。不能靠任意两图插值把三虾变一虾、四龙变金龙或四王凭空出现。

## 战局与法器红线

第一败是四条独立无翼龙压岸；第二败是唯一厚重四足双金膜翼金龙压海。老君严格在八仙和白驴脱险之后出现；施符只暂控，沧汐归方印断源、玄溟内坍、封墟、四王复形认败、八宝归主顺序不能颠倒。

八宝是八套，不是八个零件。核心中银剑/刃下粉莲/白左青右双玉；外左上葫芦、右上绿扇、左花篮、右长鱼鼓双棒、下横笛。离主后原主人对应手腰空，归还要接收而非复制。铁拐、拂尘、巨莲台和白驴不作阵节点。未到合阵镜禁止模板提前画阵。

铁拐李双肚葫芦唯一顶口、钩盖有绳；曹国舅两手两板无第三腰牌；吕一银剑一背鞘一拂尘；张一长筒两棒一白驴四腿；韩紫横笛；蓝单拱柄篮且主藤源于篮内；何手莲与巨台用途分开，格刀长杆大莲尾帧不瞬缩小花。第9章红铜甲三叉戟主虾，与A016收兵黑铜甲尖枪虾分组，不偷换演员装备。

蟹将右手锤到左手锤有换手过程：双手共同接柄→承重转移→右手释放。图生视频若不能稳定完成，就分更短续接并用真实尾帧，而不是把“换手”删掉强剪成瞬移。金龙合体/解体只在指定段允许结构改变，其他段锁头足翼尾数量。

## 声音与水印

本片保留原脚本台词功能；没有原台词与配音定稿时不让模型胡说或随机对口型。当前先生成无可辨随机对白的画面，语言/口型另做有文本音轨驱动版本。风雨、浪击、刀莲碰撞、葫芦“啵”、拍板、笛鼓等按原声音卡分轨后期制作，不能把提示词写出的音效当已生成音轨。水印如沿星火规则使用“造镜者”，由后期文字层统一制作，避免生成乱码和漂移穿脸；本包不让模型生成标识。

## 严格验收顺序

1. 提交前：核批准版本、源图哈希/像素、当前帧阶段、角色/道具数量、可见手足、支撑与关键轴线、前后状态。遮挡无证据留NEEDS_EVIDENCE，不以“过”补齐未看的技术项。
2. 提示词：只保留一主动作与一主运镜；查真人/游戏风格冲突、不能同时冻结与移动同一物体；只限制无解释变形，授权法术单列。图像实际输入与角色分工记录齐全。
3. 参数：核所选模型真实schema、原生输出、时长档、参考方式、negative传递方式和裁切策略；本包null字段未映射前不得自动提交。
4. 视频回传先登记候选：保存完整实际请求、模型版本、源图、原生W/H/fps/时长/音轨/色彩标签、输出SHA、费用与段号，禁止工具成功就记视觉通过。
5. 正常速度看全段，再慢放所有接触/抬落脚/转身遮挡再现/变形/切点；对手指、鞋底、兵器轴线、翼根、蹄、船索与水火接点逐帧检查关键窗口。若声明全段逐帧全检，必须记录总帧数与实际覆盖，不能只抽首尾。
6. 每个问题写版本、时间码或帧号、区域/可见证据、严重度、不确定性和返修约束；局部返修后回看全段与相邻切点，不允许修手换脸或修鞘换服。
7. P0：换人、多肢、多宝、穿体、无因场景跳变、剧情阶段错误，阻断；P1：握持/轴线/支撑不可信、持续闪烁、关键不可读，修后复检；P2只表现建议；NEEDS_EVIDENCE不可直接写PASS。
8. 源动作与剪辑通过后才做8K增强，增强后再复核脸手纹理、细刃、阵纹、雨线和阴影。扩帧/补帧/超分各自有派生版本，不能继承未检查的动态结论。
