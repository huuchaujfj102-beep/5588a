# R6 第17→18章因果接续修订：四王为何合龙

日期：2026-11-22  
核验范围：C17_A_S33、C17_B_S34、C18_A_S35原始ZIP；083—090关键帧与NEW_PROMPTS；140任务JSON中的F15-06、F16-01。

## 1. 源包实物核验

第17章末段F15-06对应089_F15-06.png。实物画面已经出现四条独立龙形在海面上空，海族军阵沿近岸后撤，八仙/救援队伍仍在海岸附近。该图不是“龙王还未化龙”的画面；它是四龙已在场、但尚未合体的宽景。

第18章F16-01对应090_F16-01.png，四条独立龙已进入环绕旋流，向同一中心收拢。F16-02对应091_F16-02.png，四条龙仍可分别追踪，继续向同一云核聚拢。四龙来源和身份必须保持青、赤、白、黑四条，无第五条金龙。

## 2. 当前提示词缺失的因果

C17_B包F15-06原提示词只写“雾退开、水军后撤”，没有呈现40段剧情台账中已设定的关键原因：“四王看到龙息被海眼回吸，意识到单独封锁无法稳住归墟，决定合力堵眼。”

F15-06的批准图089已经包含四龙，因此无需新增四王或重新化龙。真正缺的是可见的触发动作：四条龙的龙息/龙力被同一潮向反向牵引，四龙察觉后转向同一海面深处，开始同步向心盘旋。若不补这一拍，F16-01突然四龙向心盘旋会像无原因的编排动作，四王合龙缺少动机。

## 3. R6镜头动作修订

### F15-06｜雾消军退（承接第17章结尾）

- 输入：F15-X03真实验收尾帧；089_F15-06作为宽景目标参考。
- 0—2秒：近岸毒雾沿既定风向退薄，原岸线、礁石、渔船不变。
- 2—4秒：海族水军沿原来路后撤，近船顺浪退开，散兵不瞬间清空。
- 4—6秒：画面上空四条既有龙的龙息/龙力被同一股潮向反向牵引，能量流线向同一海面深处回卷；四龙分别察觉，先转头，再调整身体朝向，形成向心盘旋的初始方向。
- 结束状态：四龙仍是四条独立无翼龙；尚未合体，尚未出现唯一金龙；老君不出现。
- 剪辑：用四龙视线/能量回卷方向切入F16-01，不强制同机位首尾续生。

**修订正向提示词：**

“从F15-X03之后的同一风暴海域接入，使用089_F15-06宽景作为目标构图参考。近岸毒雾先沿既定风向退薄，海族水军沿原来路缓慢后撤，近船顺浪退开。画面上空已经存在青、赤、白、黑四条独立龙，保持各自原有龙体、颜色、鳞片、无翼形态和相对位置。随着近岸雾退，四龙吐息/龙力出现被同一股海潮向深处回吸的牵引，四条能量流线分别从龙口/龙身附近向同一海面方向回卷；四龙依次察觉，先转头锁定同一方向，再调整身体姿态开始向心盘旋。只建立合力堵眼的决定与运动动机，本镜不合体、不长出金色实体、不出现第五条龙、不出现老君。”

### F16-01｜四龙盘旋（第18章开场）

- 输入：A064/090_F16-01批准姿态。
- 延续四龙在上一镜已被潮向牵引、视线一致的动机；四龙沿各自既有盘旋弧线向中心靠拢。
- 保留四条身体之间的独立间隙，四条龙仍可分别辨认。
- 云雾先被四条轨迹带动，中心旋流逐步形成；本镜只到“向心收拢”，不提前进入四色龙身入核或金胸初显。
- 结束状态接F16-02：四龙已朝同一中心收拢，但仍保持四条来源轨迹。

**修订正向提示词：**

“从四龙已察觉龙息回吸、朝同一海面深处转向的状态继续。青、赤、白、黑四条独立无翼龙沿各自原盘旋弧线同步向同一中心靠拢，保持四条龙体间隙和各自颜色/头尾/体型可辨；先带动云雾与海面气流形成旋流，再逐步收紧盘旋半径。动作只到向心收拢，不进入云核、不金粒化、不出现厚金胸廓、不出现双翼或完整金龙。末帧接091_F16-02四龙仍可分别追踪的汇聚状态。”

## 4. 时间与版本冲突

当前C17_B ZIP的F15-06提示词标注6秒；C18_A ZIP的F16-01提示词标注7秒。140任务JSON中两镜positive_prompt均写“有效镜长约3秒”。这是明确的跨版本时长冲突，不能同时作为生成请求依据。

R6本轮不擅自把3秒或6/7秒写成最终模型时长。建议以40段生产包和分镜时间码为剪辑时长参考，重新统一140任务JSON的时长字段/正向提示词，并按实际选用模型上限拆分请求；在统一前，这两镜参数门禁保持BLOCKED_FOR_SUBMISSION。无论生成时长如何，剪辑有效动作必须完整，禁止慢放凑时长。
