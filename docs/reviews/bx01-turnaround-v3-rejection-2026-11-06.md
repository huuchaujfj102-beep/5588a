# BX01 铁拐李 V3 补图复核｜2026-11-06

对象：本轮生成的两版 BX01 综合多宫格人物设计板，属于概念校正稿，不属于生产可用的五张独立无字母图。

## 审核结论
**REJECTED / P0 未清零。禁止升级为 APPROVED_STILL 或 APPROVED_FOR_I2V。**

已改善：人物基本年龄、灰发长须、旧衣破损、老者气质和海岸光影统一；五方向视图的初步布局已覆盖。

P0:
1. **铁拐形制漂移**：主体视图、单品区的拐杖头分别出现圆钝头/复杂弯钩与分叉形态，不是同一法宝。须先锁定唯一官方款铁拐，五视角一根杖，不能凭空变化。
2. **葫芦形制/数量与挂点漂移**：部分展示为两个或多枚葫芦，多个局部板块图样不一致，佩戴位置在视角间漂移。应只有一个唯一紫金葫芦，同一葫芦的纹样、形状、绳结与持/挂状态必须解释清楚。
3. **五视图尚不具备严格几何对应**：左侧90°、右侧90°反向关系及前后服装层次需要真正同一个角色建模参考，不宜拿生成的多宫格图直接作为生产母图。

P1:
- 跛足仅在静态姿态与绑腿中间接体现，未通过三阶段步态/重心验证；不能直接允许动作I2V。
- 画面多处中文字不精确；角色资料和参数以仓库机器可读文字表为准。
- “8K”字样不等于实际8K渲染。

## 修复指令
A. **先单独法宝资产锁定**：唯一拐杖（确认采用圆钝杖头还是弯钩杖头；以用户先前批准的法宝单品图为准）、唯一紫金葫芦，禁止多变体混用。
B. **再出5张独立无字人物全身单图**，顺序正面0°→左前45°→左侧90°→背面180°→右侧90°，每张从已批准的同一角色参考版本进行图像编辑而不是新建脸。
C. **独立检查跛足步态**：固定跛足侧与持杖手后输出落杖/移重/迈步3个关键姿态，检验足底和杖脚接触，之后5–10秒单动作视频样片。
D. 每张出独立QA清单，P0为零，P1有批准记录才晋级。
