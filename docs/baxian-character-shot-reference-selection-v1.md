# 《八仙过海·沧海证道》人物按景别选图与最多两张参考的硬门禁 V1.1

> **AI智能体纯生成模式（2026-11-07）**：本项目无实拍摄影机采集、真人现场同期声或ADR补录；镜头焦段/机位指虚拟镜头，人物与场景按黄金样张/环境锚图/道具锚图生产，配音为AI语音与逐句口型同步。技术交付指标以实际AI生成和合成后的媒体参数为准。详见 [纯AI电影脚本与交付规范V4](baxian-ai-film-screenplay-and-delivery-rules-v4.md)。


日期：2026-11-07。适用：**所有人物**（当前BX01–BX08及后续角色）、文生图/人物局部精修/图生视频首末关键帧及群像人物逐层制作。用户直接指定的硬规则优先于此前“全部六视图同时提交模型”的做法。

## 1. 景别和参照图片一一对应

| 目标镜头 | 必选人物参考 | 人物参考图数量 |
|---|---|---|
| 特写 / 近景 | 正脸特写 + 45°侧脸 | 1–2张 |
| 中景半身 | 正面全身 + 45°侧身 | 1–2张 |
| 全景 / 全身 | 正面全身，且只用这一张 | **1张** |
| 背影镜头 | 背面全身 | **1张** |
| 侧面动作 | 正侧身 + 背面 | 1–2张 |

**全局硬规矩：一次生成调用的输入参考图片总量永远不超过2张（人物、道具、姿态、场景等所有实际传入模型的参考图合计），并且每张都必须与目标景别、主体朝向或具体可见道具相匹配。** 不接受“为了保险把六视图全塞进去”；不接受将六视图拼成一张图片来绕过两图限制。生成前必须逐张登记 `reference_file`、`reference_role`、`shot_type`、`view_angle`、`approved_sha256`、`visible_in_shot`，不匹配或张数超限即 **BLOCKED**，不得开始生成。

## 2. 道具母图与两图总上限如何同时遵守

- **道具是独立锁定资产，不因该镜头只允许1–2张参考而失去保真要求。**
- 近景若人物形象需要两张人物参考，则道具母图不作为第三张生成参考；改用现成已批准法宝透明层进行**非生成式合成**，或先进行该道具独立生成/精修（每次≤2张）并验收，再与人物合成。
- 若镜头中必须突出某件法宝，可以在 **2张总额** 内选择1张与目标角度匹配的人物图＋1张该法宝母图；人物另一角度仍用于**离线人工审核**，而不是额外送入生成模型。
- 全景/全身场景，人物生成阶段严格1张批准正面全身，不追加其他人物角度；道具使用批准透明层单独合成。
- 六视图可全部用于**生成前人工核验、身份对照、审片**；“审核读到多少张”与“单次生成向模型输入多少参考图”不是一回事。
- 群像严禁一次性整幅重生成八个身份；八人分别按自身镜头景别/角度执行≤2张参考及各自法宝锁定，然后做有SHA来源的分层合成。
- **不能通过数图上限就虚报一致性**：如果规定参考缺失、未获批准、角度不匹配、法宝形制未锁或人物原图不可读取，一律P0阻断。

## 4. 每次出图的硬核QA

按人物、景别、朝向、六视图一致性、脸/发型/服饰/体型比例、法宝唯一归属/母图纹样、剑鞘状态、手脚数量和握持、站位、场景地理、光影和物理接触进行审核。P0>0不提交用户最终批准，不进入I2V。参考图张数合规只是必要条件，不等于角色或成片视觉自动合格。


## 5. 生成模式强制路由（2026-11-07 新增）

| 生产任务 | 唯一允许的生成模式 | 例外/门禁 |
|---|---|---|
| 从零出角色定妆、概念探索 | 文生图（text-to-image） | **只限建库阶段**；未签核不得作为正式角色母图 |
| 已有批准角色图，要出该角色的新镜头 | 参考图生成（reference / img2img） | 目标景别匹配，单次输入图像**最多2张**；角色/法宝视觉漂移即P0 |
| 人物已定，仅改服装/道具/背景/光影 | **局部编辑（inpaint / reference edit）** | 遮罩只允许变更批准的指定区域；改服装或道具属于**新版本候选**，必须重审，禁止覆盖已批准原件 |
| 出视频 | **锁定首帧 → 图生视频（I2V）** | 首帧需已批准且可追溯SHA256；无批准首帧禁止文本自由生成视频冒充合格版本 |

必须先判断任务阶段 `asset_library_stage|locked_character_new_shot|locked_local_edit|video_i2v`，再确认所选模型/接口模式。模式错选立即BLOCK，不执行渲染。

## 6. 五层分离生产主链（2026-11-07 新增）

| 层 | 生成及制作动作 | 锁定资产/检查 |
|---|---|---|
| **L1 角色定妆** | 纯净背景＋目标服装＋目标光位；独立人物出图、六视图核对 | 获批后锁为**黄金样张（Golden Character Master）**，保存原始文件/SHA256/批准版本；不得用场景重画替换 |
| **L2 场景空镜** | 不含任何人物，单独生成远中近空间、视线关系、风浪与主光 | 锁为**环境锚图（Environment Anchor）**，保存相机轴线、焦距、光向、色温、场景坐标和SHA256 |
| **L3 道具细节页** | 净底单道具；分别审查正视、45°、俯视三角度及材质、比例、固定纹样 | 锁为**道具锚图（Prop Anchor）**。三个审查视图**不是要求一次生成上传3张**；必须按任务拆调用，每次≤2张，归属锁ID/SHA256 |
| **L4 合成** | 只将已批准角色图层与已批准道具层置入环境锚图；控制前后遮挡、相机透视、接地、同光源/色温 | 首选无生成式RGBA分层合成；需要inpaint时仅局部遮罩边缘/阴影，**不得把角色＋场景＋法宝3张图一次输入模型**。合成属于候选，未过审核不得升级黄金样张 |
| **L5 修补** | 只修手指/道具接触、鞋底、物体边缘、飞发、水花衔接和接触投影 | 锁定脸/发型/服饰/法宝主体不得动。局部修改前后须记录遮罩、改动像素区域、源文件和审批证据；仍使用≤2张匹配参考 |

**强约束优先级**：先锁黄金样张、环境锚图和道具锚图 → 各自单独审核 → 图层合成（不是整幅生图）→ 局部inpaint → 八人逐人/逐法宝与环境物理质量审核 → 用户终审 → 视频锁定首帧I2V。任何层级缺批准原件、角度参考不符或SHA256变更未登记，一律停止。

**注意区分**：前置人眼阅读/比对完整六视图和道具三视图不受“生成输入≤2张”的限制；限制的是**一次实际向生成模型发送的全部输入参考图数量（含人物、法宝、环境、姿态等）**。不允许以多图拼贴到一张的方式绕开此限制。

**交付证据**：每次镜头至少登记 `character_master_sha256`、`environment_anchor_sha256`、`prop_anchor_sha256`、`reference_images_sent`、`model_mode`、`shot_type`、`target_angle`、`composite_layer_manifest`、`edit_mask`、`qa_status`、`user_approval`。没有真实素材及逐图QA结果，不得宣称五层全部已实作或验收通过。


## 7. 单镜头标准提示词七字段模板（2026-11-07 新增）

此模板适用于**人物已定型后**的参考生成/参考编辑。实际生成只允许1–2张输入参考；并先通过景别/朝向匹配门禁。**图1人物黄金样张+图2环境空镜**仅当人物角度匹配目标镜头时适用。如果目标视角必须用两张人物参考，则场景须使用已审核的环境锚图，通过非生成式分层合成进入，不能作为第三张生成输入。

### 7.2 状态机覆盖示例，而不是覆盖角色母图

- **仙宴/闲谈镜头**：BX03 吕洞宾默认 `SHEATHED`，剑刃不外露；不得根据本模板擅自拔剑。
- **战斗/拔剑镜头**：分镜明确有“拔剑”事件后，才允许 `DRAWING`/`DRAWN`；鞘同时变空且总剑数恒1，收剑有单独 `RETURNING` 动作。
- 实际人物六视图与法宝母图均需先在审片阶段逐图核验；向生成模型提交的仍是目标镜头最合适的最多两张参考。
- 所谓“唯一身份依据”是指**图1锁定该次出图的身份**；完整六视图和角色批准档案依然是验收依据，绝不从整幅群像反推身份。
- 若出图任务是**修改已批准素材**，把 `generation_mode` 改为 `inpaint` 并提供局部遮罩；不允许整图自由重画。


## 8. 三道质量检查门禁（2026-11-07 新增）

| 检查 | 触发时机 | 逐项检查内容 | 放行条件 |
|---|---|---|---|

### 8.1 自检的必填十项 checklist

- [ ] 脸：五官结构、年龄、面型未变，不能换脸
- [ ] 发型：发际线、发髻、头饰、发色与批准定妆一致
- [ ] 服装款式：裁片、层次、腰带、袖口、鞋子与黄金样张一致

- [ ] 手指：双手、手指数、指节、物体接触及遮挡物理正确
- [ ] 光位方向：脸/衣袍/法宝/地面投影的主光与补光方向一致
- [ ] 色温：主体、背景、反光和阴影色温可信并衔接前后镜
- [ ] 画幅：景别、取景范围、横竖比、人物完整性符合分镜
- [ ] 文字/水印：无多余文字、乱码、模型水印及无授权标识；项目正式要求的水印按版本规范单独验收

### 8.3 拦截准则

1. 三道门禁有严格时间顺序：**出图 → 自检 → 黄金样张比对 → 候选批准/锁首帧 → I2V → 实际剪辑前下游复核**；尚未到达下一阶段时该阶段填 `PENDING`，不能虚报完成。
2. **P0**：人物身份/眉眼或面型显著漂移、法宝错人/换型/复制、关键肢体错误、未批准首帧直接进入视频、视频镜头有重大不连续。任何P0都必须 `BLOCKED`。
3. **P1**：轻度纹样偏差、可控的布料边缘、局部光温不一致、镜头过渡不稳；必须有明确修复计划、责任与复检记录，不能默认当作通过。
4. **P2**：仅限小范围可逆后期瑕疵，需在终版前关闭。
5. **图片自检/并排比对完成 ≠ 视频下游检完成**。不能因为视频尚未生成就给下游打PASS。
6. 群像需**BX01–BX08每人各自完成自检与比对检**，每件批准法宝分别核对母图；全片前后镜另按镜头级检查。
7. 审核机制除了文字规范，实际生产程序必须显式调用这些检查；未实装机器视觉的项目不得声称已自动证明脸型相同、道具合格或场景物理正确。


## 9. 生成前“三类锚图一致性”强制门禁（2026-11-08）
