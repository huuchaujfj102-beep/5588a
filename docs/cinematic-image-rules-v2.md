# 电影级 AI 文生图与连续镜头防穿帮规范 V2.0

> 适用于 OneFlow / FLUX 文生图输出、Seedance 等图生视频输入、Remotion 合成前审图。**这是质量约束与人工复核 SOP，不是生成成功率保证、模型画质提升开关或自动通过证明。** 不覆盖用户指定的特殊艺术设定。

## 1. 全局优先级与例外
- P0 **故事/参考资产事实**：已批准的人物脸型、服饰、车辆结构、建筑地图、标识位置、镜头方向优先，不得因为模型美化自行更改。
- P1 **物理与连续性**：解剖、支撑、遮挡、透视、接触点、光源与阴影、镜头衔接。
- P2 **影视观感**：材质 PBR、真实纹理、景深、曝光、高光、层次、颗粒、风格。
- P3 **审美增强**：饱和度、史诗感、粒子、体积光不得破坏 P0-P2。
- **明确允许例外**：魔法悬浮、飞行器喷射、动漫夸张比例、倾斜镜头、复杂多光源、艺术化非 PBR 等，必须在资产卡/分镜中明示其规则及因果关系。不要机械坚持“仅一个光源”；应为**主光逻辑明确、辅光/环境光一致**。
- “8K / UE5 / Cine 镜头”是视觉参考词，不代表模型原生分辨率或真实渲染引擎；最终按实际像素与工具链验证。

## 2. 单帧硬门禁（P0）
1. **解剖**：可见手应具有正确手指数量和关节连接；四肢、耳眼鼻唇、头发附着与生物角翼尾根部结构合理，不多肢、粘连、穿体、错手掌；被遮挡手指不能按“必须显示五根”误判。
2. **道具/机械**：刚性轮廓连续，螺栓、铰链、绑带、车轮、进排气、支撑点连接合理；透视下左右不一定像素对称；禁止随机孔洞、融化、穿模、凭空多零件。
3. **空间**：同一相机投影模型下消失点一致（多组平行线各有各自消失点）；门窗比例、地砖接缝、遮挡前后顺序、地平线及地面接触阴影合理。镜头旋转或广角边缘畸变须与镜头卡匹配。
4. **文字**：精确 logo、招牌、文字必须用批准素材图/后期叠加，不可靠纯生成猜字；没有素材时留干净标牌或可控虚焦。禁止随机乱码。禁止擅自新增水印；如任务指定“造镜者”，在后期按专属水印卡制作。
5. **光影**：主光方向/色温与镜头卡一致，所有可见投影符合各光源叠加关系；阴影软硬/长度受距离、光源大小与时间控制；反射不得出现不存在的主体；体积光需有来源。
6. **PBR**：基础色、金属度、粗糙度、法线与表面微结构一致；非金属皮肤/布料/木材不可随机呈镀铬；皮肤等适用 SSS，金属/石块不得错误套用；玻璃折射、菲涅尔、雾衰减要符合材质。
7. **物理/天气**：悬浮必须有剧情内动力解释，布料有重力与风向；雨湿地面与雨滴统一，烟火来源和流向合理，水流遵从坡度/重力；远景空气透视自然。
8. **光学**：相机机位、朝向、焦段和主体透视关联；焦点及景深合理；运动拖影与快门逻辑一致；不以虚假锐化、伪纹理、过饱和掩盖瑕疵。

## 3. 跨镜头一致性（必须建立资产真值）
使用 `scene_id`、`shot_id`、`continuation_of`、`character_ids`、`asset_ids`、`approved_reference_sha256`。
- **角色卡**：人脸、骨相、肤色/瞳色、发型、服装、饰品、伤痕和可变状态；角色不同镜头须一致。
- **场景卡**：以文字或空间示意固定左/右门、立柱、楼梯、标牌朝向、主要道具坐标及可变对象；换机位时允许透视导致位置投影改变，但不能改变世界坐标。
- **道具/机械卡**：握持手、轮位、喷口和结构、状态；同一动作前后必须守恒，不凭空增减。
- **灯光卡**：时间、主光方位/色温、实景灯位置与曝光、调色 LUT/色彩曲线；切镜时允许有合理曝光变化。
- **镜头卡**：机位、朝向、焦段、焦点、景别、相机高度、预计运动（一次一类主运镜）；上一镜尾帧和下一镜首帧应检查场景与动作衔接。
- **状态时间线**：动作阶段、手持道具、门开合、车辆喷口启停、衣服污渍、环境天气；换装等变化须有剧情事件。
- **同底图优先**：连续推拉/轻摇可优先采用经批准关键帧图生视频，不盲目每帧重生。

## 4. 提示词编排（正向）
顺序：**批准资产与世界规则锁定 → 本镜头可见主体/精确动作瞬间 → 空间与遮挡 → 主辅光与材质 → 机位/焦段/景深 → 电影化质感与实际输出参数 → 负面约束**。
正向提示词必须具体说明：谁、在哪里、站姿/手部、穿什么、拿什么、镜头方向、光从哪来、地面与天气、什么不能改变。
不要把全部禁令塞入正向文本造成注意力稀释。简明的实际模型前缀见 `oneflow/cinematic_image_rules.py`。

### 模型适配
- **FLUX / 文生图**：将关键约束写入正向提示词；当前 OneFlow HF 接口没有单独提交 negative_prompt 参数，记录于 plan 不等于模型接收独立负面通道。
- **Seedance / Vidu / 视频模型**：本规则用于首帧和跨帧审查，视频动态仍沿用七模块（原图锁定、局部微动、环境、单一主运镜、光影、技术、负面）。
- **Remotion**：负责合成、标识/水印/文字叠加和技术验证，不会自动修复解剖/空间穿帮。
- **精确文字**：优先后期排版，避免以模型文字输出替代。

## 5. 审图 SOP
| 编号 | 检查项 | 失败处理 |
|---|---|---|
| A01 | 人体/生物拓扑和关节 | 不合格重生/局部修复 |
| A02 | 道具/车/建筑零件 | 锁定参考后重生 |
| A03 | 透视、尺度、遮挡和接触 | 校正机位/场景卡 |
| A04 | 光影、色温和投影 | 校正灯光卡 |
| A05 | 材质、反光/折射、纹理 | 校正材质描述 |
| A06 | 天气、重力、烟火和液体 | 校正世界状态 |
| A07 | 字符、品牌、标识与水印 | 后期合成或重生 |
| A08 | 镜头焦距、景深、清晰度 | 校正镜头卡 |
| A09 | 人物身份服饰与道具连续性 | 回退到批准参考 |
| A10 | 地图、时间线和前后镜头动作 | 回退到资产/时间线 |

**状态字段**：`PENDING`、`PASS_HUMAN`、`FAIL`、`WAIVED_WITH_REASON`。未检查的项不得判 PASS；机器可以验证 JSON 字段、尺寸、SHA、帧格式，无法仅凭文本证实真正无穿帮。P0 故障禁止交付；豁免须有具体戏剧/物理设定及人工签核。

## 7. 发行前要求
生图完成 → 核对实际尺寸/文件完整性 → 逐项人工/视觉审图 → 锁定批准关键帧 SHA → 图生视频 → 首尾帧/镜头连贯性复检 → 音画字幕/版权/水印/技术审核 → 人工终审。未批准首帧不得自动发布。
