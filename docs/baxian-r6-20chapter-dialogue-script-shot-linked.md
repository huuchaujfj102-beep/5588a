## 执行规则

- 每句对白绑定真实 `shot_id`；没有可靠画面承载的台词不强行塞进镜头。
- 表中“画内”表示近景/中景可见角色发声；“画外/场外”表示声音跨镜或远景，不要求假口型。
- 时间码暂记为“随剪辑锁定”：先按动作节拍录制，拿到最终视频后再做逐字时间码与口型校准。
- 口音强度0—3，八仙常态为1；所有台词以清晰普通话为准。
- 音量：低/中/高；高只用于战场命令或情绪峰值，不等于持续吼叫。
- 每句对白后保留动作呼吸空间；不得用对白覆盖兵器接触、笛鼓节奏、救援呼喊等关键声音。
- 没有列台词的镜头，优先保留环境声、动作声和表演停顿，不为了“热闹”而加旁白。
