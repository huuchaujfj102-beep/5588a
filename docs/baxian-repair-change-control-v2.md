# 《八仙过海·沧海证道》修图 / 改图 / 关键帧整改一次性闭环规范 V2.0
**生效日期：2026-11-06｜权威优先级：本文件覆盖旧文档中“每发现一项立即再生图”的做法；最终定型批准权仅归用户本人。**
适用：角色五视图、道具、建筑、场景、群像、战斗图、首中末关键帧、其他重要美术资产。
目标：将同一轮发现的全部问题尽量一次解决，减少反复生成与重复成本；**不保证AI一次绝对无误**，但禁止未完成整改预检就直接再次生图。

## A. 固定资产基线，先治根因
1. 指定 ONE_SOURCE_OF_TRUTH：角色面部、服装、法宝、场景分别绑定已确认的源图ID + 哈希/版本 + 当前状态；若用户尚未确认，标「候选」，不得擅自称“已定型”。
2. 构建**不可变项目锁表**：脸型/年龄/发色/身材/服饰裁片/道具款式、数量、佩戴坐标/角色左右/光向/建筑布局/镜头轴线。
3. 同一视角的定向修复优先遮罩编辑、参考绑定和局部重绘；缺失视角单独基于同源重建，禁止误当作镜像、禁止随机全图重新生成、禁止无请求生成带“审核通过”字样的海报。
4. 已确认正确的区域为 PROTECTED（绝不改动），拟修改区域为 EDIT_MASK；内容相依时将联动区域纳入掩膜，并检查边缘融合与阴影。

## B. 问题一次性汇总：冻结问题清单，禁止边改边生成
一张图/一组同角色图先完成全覆盖诊断，七个**审核岗位职责**（非声称七名实际真人已操作）：
- 编剧：故事动机、场次时序、人物与动作因果；
- 人物美术：身份、面部微表情、皮肤肌理、五官/发须/服饰/四肢与足部；
- 道具美术：法宝数量、形制、左右手、挂点、归属、状态、比例；
- 场景建筑：建筑/道具几何、位置、磨损、物理连接与景别；
- 摄影灯光：主光向、阴影/反射、天气、色温、焦距、真实摄影肌理；
- 动画特效：重心/接触/法术能量/风水物理/首尾运动方向；
- 连续性总审：角色五视图与镜头间对齐、镜头轴线、版本与哈希、缺陷交叉复核。
每一缺陷形成**唯一 Issue ID**：区域、问题证据、P0/P1/P2、根本原因、应改成什么、必须保持什么、影响到哪些其他镜、实施方式、客观验收标准、责任审核岗位、状态。
检查涵盖所有局部放大：眉眼、鼻翼、嘴唇、耳、皮肤纹理、手指/掌纹、脚趾、鞋底、关节、铁拐/佩饰、布料裂边、光源与景深、背景结构。**不能仅写「不够写实」「优化一下」等空泛意见**。

## C. 先做完修改方案再生成
1. 七岗位依据 ISSUE_MATRIX 逐项提出可操作修复指令，不是仅给建议。对有冲突的指令先裁决，例如右手持杖与左右翻转/背视图映射；对不同帧明确状态转场。
2. 合并为一个 **REPAIR_PLAN**：固定资产+问题区域+局部遮罩+必要参考+统一正面提示+分角色/分道具负面词+5视角映射+镜头连续性+验收规则。
3. 实施前执行 **PRE-GEN QA**，逐条检查：
  - [ ] 全部已发现 P0/P1 均在修复计划有明确方案，未解决的事实冲突/参考缺失列 BLOCKER；
  - [ ] 新旧道具、左右方位、数量和场景状态无冲突；
  - [ ] 模型能实现的编辑手段已确认；不支持局部编辑就先说明，不可假装已修；
  - [ ] 需要的参考图、遮罩、五视角源图和技术参数已齐全；
  - [ ] 修改计划不会破坏通过区域；对受影响的关联图有复核清单；
  - [ ] 预计一次出图的所有硬要求已写到提示词与负面约束；
  - [ ] 已定义明确通过门槛、验收者和原图归档回退路径。
4. **PRE-GEN QA 未通过：禁止提交修图生成请求。** 应先补足参考/计划或说明障碍，不能继续循环无效重生。
5. 预检合格后只针对需改区域执行**一次完整修正版生成批次**。多视图是一批相关资产，但每张有独立文件；不允许以拼贴图冒充单张生产资产。

## D. 生成后一次性系统复核与闭环
- 新图对比旧图及保护区域，逐条打勾 Issue：FIXED / REGRESSED / UNRESOLVED / NOT_APPLICABLE，附证据截图或局部对比。
- 再按同样七项全量审查，重点检查修复引入的新缺陷（regression）；一图一审，跨视角/相邻帧额外审查。
- **P0=0且P1均已解决或形成明确人工风险签署**时，仅可标记 TECHNICALLY_REVIEWED / READY_FOR_USER_REVIEW，不得由AI或审查组标记 FINAL_LOCKED。
- 若仍失败：停止自动连续生成；先出《失败根因对照表》说明哪一条预检不足/模型能力不足/参考冲突，再修订总方案。禁止把同一问题在多轮重复生成而不改变方法。
- 不得承诺一次100%通过、虚构8K、虚构视频检查或称生成海报上的“通过章”为真实验收。

## E. 用户最终拍板：唯一放行权限
**只有用户明确确认“通过 / 定型 / 采用这版”后，才能将图标为 USER_APPROVED_FINAL，并绑定确认的 asset_id/version/hash。**
- 若用户提出修改意见，按B和C重新整理**整套本轮意见**，先修订方案，禁边改边生；旧批准版保留可回滚。
- 用户未批：状态 USER_REVIEW_PENDING；不得合并为最终母图、上传替换已批准母图或投入正式图生视频。
- 技术检查通过≠用户最终确认，用户最终确认≠省略物理/安全审核。若P0存在必须先修复，即使画面好看也不得技术放行。
- GitHub上的规范变更仍需人工PR审阅，未经授权不合并main。

## F. 对 BX01 的即时应用
已知：铁拐圆钝头、紫金葫芦唯一性、左腰佩挂、右手拄杖、左腿跛足为候选且应核定、面部微表情候选A；五视角缺右侧90°、葫芦由左手托持与左腰佩挂存在状态冲突、步态真实运动未验证、海报型拼图不能当5张独立图。**因此先提交Issue矩阵与修复方案，经生成前检核后再制作修正版；不得在同一轮连续尝试整张随机重绘。**
