## 二、重点纠错

### 1. 第01章：灯火、海底旧门、越堤巨浪之间必须明确为因果交叉剪辑

现有顺序：
- F01-02：阿宁与小满守住铜灯；
- F01-03：海底旧门禁纹裂开、黑水外涌；
- F01-04：同一海域第一股浪越过防波堤。

R6覆盖：
1. F01-02结尾先稳住灯芯，保留灯焰低频声与门外风声。
2. F01-03不把铜灯/人物硬搬到海底；用灯焰暖光短暂反射匹配旧门禁纹，风声低频化为海底闷响，黑水从旧裂口向外喷出。
3. F01-04由同一股黑潮压力传到海面，浪峰沿既定海向越堤；不把海底喷流直接变成无空间逻辑的巨浪瞬移。
4. 这是有动机的跨空间剪辑，不要求F01-02尾帧与F01-03首帧像素续生。

### 2. 第06—07章：救援、母子护灯、玄溟幻象、沧汐读壁刻必须用明确平行剪辑串联

实际包内顺序为F06-01、02、03、06、07、04，之后第07章F06-05与R5-E01。不能按镜号数字重新排序，也不能让镜头看起来像人物从海岸瞬移到神殿。

R6覆盖：
- F06-03：吕洞宾收剑转身护住眼前孩童，落脚挡住来潮；以剑入鞘声/孩童喘息做切口。
- F06-06：切至阿宁与小满在家守灯的平行场面；母亲示意先救人，孩子继续护灯。明确这是同一场灾潮中的另一处空间，不是F06-03孩童瞬移回家。
- F06-07：黑潮水影/玄溟幻象浮现，表现灾潮借恐惧映出八仙失败景象；幻象不等于现实八仙或实体法器离主。
- F06-04：以水影旋涡/壁面反光匹配切回半沉神殿，沧汐持印触读旧刻；人物位置不跨空间连续移动。
- F06-05：在同一壁面、同一印与发簪状态下继续揭示守海记忆代价；印始终在沧汐手中，尚未归槽。
- R5-E01：沧汐迟疑并收回触壁手，保持托印，目光转向殿外；不得把她的守海记忆损失提前表现为完全失忆。

### 3. 第08章：四王封海的军令动机要从画面中看得见

F07-M01已批准图032显示太子以长枪横拦救援船，画面本身尚不能说明为何拦船。现有剧情动机是救援船船底/尾流附着黑潮，四王担心污染进入禁区；太子按军令执行，而不是无缘无故阻拦村民。

R6覆盖：
- 只在既有船底与尾流增加可辨但克制的黑潮附着/回卷水色，不新增船、人、武器或标识。
- 太子先看见黑潮随船尾流越过禁界，再横枪阻行；船只受阻回摆，村民扶稳船沿。
- F07-M02切吕洞宾站到枪路与村民之间，吕不拔背剑、不先攻击；太子收枪对峙，双方因救人优先级和禁令产生误判。
- F07-04以海族右、八仙左、救援路在中间的固定轴线结束，不能在对峙镜头中随意换边。
- 若黑潮附着无法在现有批准图/模型中稳定表现，必须用一个短插入环境镜或音效+特写补足，不可只靠台词解释。

### 4. 第10章：蟹将方锤交手存在关键动作相位断点

实物图：
- 041_F09-03：蟹将右手持方锤，左手空；
- 042_F09-04：方锤已在蟹将左手，右手空并作示意；
- 043_F09-05：左手持锤、右手向左挥令。

原F09-03提示词只写左手扶到锤柄、右手仍持柄，结束时仍是双手接触，没有明确右手松开；F09-04参考说明又写“先放低锤右手交左手”，但其实际参考图042已经完成换手。模型可能在F09-04重复换手或倒演。

R6覆盖：
- F09-03：右手持锤答话→左手先握稳锤柄→右手确认左手承重后松开→方锤完整转至左手，匹配042。
- F09-04：从042“左手已持锤、右手已空”的完成状态开始，只让虾兵稳定三叉戟、蟹将右手指向左前；绝不再次换手。
- F09-05：保持左手锤、右手发令，挥令方向与虾叉朝向一致。
- 锤不离手、不复制、不交换主人；动作必须一镜一相位，不做瞬移。
