## 成本量级（只按输出时长粗算）

- 当前40包主提示词15分51秒：若全部按Wan 3.0 $0.045/秒，理论基础生成费约$42.80。
- 100分钟目标：同价按6000秒估算约$270。
- 100分钟若全部按Kling v3 Standard $0.14/秒，理论约$840；按Kling 4.0 $0.157/秒，理论约$942。
- 上述未包含失败重试、补帧、放大、音频、文件托管、税费或供应商价格变化。Seedance按token计费，不能简单换算成每秒单价。

## R6建议工作流

1. 先选3类镜头做小样：静态环境、人物动作/法器交互、复杂多人/龙形变身。
2. 以Wan 3.0作为低成本基准，Seedance 2.5作为质量对照；复杂多关键帧镜头再单独评估Kling 4.0。
3. 同一批准图、同一动作prompt、同一时长、相同分辨率做A/B测试，检查人物一致性、动作物理、法器数量、帧间闪烁、尾帧命中率。
4. 通过后再按镜头类型路由模型，不用一个模型硬做全部镜头。
5. 正式批量前必须先完成84分09秒的故事扩容，并统一140任务JSON与40段包时长冲突。
6. 用户未确认批量预算前，不提交整片批量生成。模型目录搜索、schema读取与价格查询不是视频生成。
