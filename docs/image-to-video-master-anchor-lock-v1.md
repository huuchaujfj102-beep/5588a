# 《基准帧锁帧防跑偏规范》V1.0｜通用图生视频生产门禁

生效日期：2026-11-11；适用：星火3.0、宋韵江心对谈、八仙群像、Seedance 系列及其他支持参考帧的 I2V 模型。**此文是生产规则，不是已经完成的模型实测报告。**

## 0. 原则与优先级
**主基准帧（MASTER_ANCHOR）是整场戏的唯一空间世界锚点；任何片段都要关联主帧，不得只靠上一段视频末帧滚动接力。** 实际模型若仅允许单张输入，应使用主帧并将末帧作为人工对照/剪辑接续依据，而不是谎称模型支持多参考。已有项目批准的角色多视图/道具母图/关系图优先于主帧中可能存在的生成缺陷；P0 不得因“主帧已锁定”而继承。

规则优先级：用户批准的角色与道具资产 → 审核通过的场景主基准帧 → 审核通过的镜头子基准帧 → 上段结尾帧（弱参考，仅辅助动作连续） → 文字提示词。所有分支都必须记录来源ID和SHA-256；主基准帧只读，不直接改写。

## 1. 主基准帧一次性建立（MASTER_ANCHOR）
- 用稳定的静态图生成或非生成合成建立场景，命名 `MASTER_江心对谈_v01.png`；记录 `scene_id, anchor_id, source_sha256, width, height, approved_by, approved_at, asset_refs`。
- 江心样例：江心孤石；左/右人物黄衣谪仙、老渔翁位置由批准图确定，**禁止凭文案猜左右**；陶罐居中、果篮在渔翁一侧、石鱼前景左下；红日画面右上；远山、江面、晨雾与晨光固定；不引入仙鹤。
- 保存世界空间地图：画面归一化坐标 `[0,1]`（每个角色头/脚/道具中心及包围框）、前后遮挡、地面接触点、视线方向、镜头视角、主体高度。允许在**同一物理世界**中有限重新构图，但不得错误地把屏幕坐标锁定与真实推镜投影变化混为一谈。
- 锁定相机侧别和180°轴：两人连线为戏剧轴，主相机位于已批准侧；换镜头需要先有单独审批的静态机位图，不得隐式越轴。
- 锁定相对环境：主光由右上方红日方向投射暖金侧逆光；阴影与丁达尔体积光方向一致；天候/远山/岸线/岩石/道具的身份和拓扑不漂移。
- **三道静态预检**：①人物多视图/身份服饰；②法宝/道具母图数量、几何、状态、归属；③手脚、嘴/杯/地面等接触关系和空间光影。任一P0失败则BLOCK，重修静态候选并复验，不能以不合格图生成视频。
- 通过后冻结主帧原始字节及SHA-256，存只读母库；视频首帧可做经记录的无裁切比例适配副本，副本不能冒充原图。**不得用有漂移的视频截图反向覆盖主帧。**

## 2. 每段 12 秒制作前的固定门禁（先校验模型能力）
1. `mode=image-to-video`；每段必须关联并在模型支持时实际上传主基准帧。静态子基准帧必须记录与主帧的父子关系。
2. 重用稳定的硬锁参块，仅变更本镜台词、合法微动作和**单一**运镜。对白：`静帧呼吸`（相机基本静止）；氛围：`极慢前推`。禁止未经批准的横摇/环绕/甩镜。
3. 固定镜头目标：`duration=12s`、`aspect=16:9`、`model=用户指定的 Seedance 2.0 Mini`，**前提是对应账号、接口、模型版本实际支持12秒和该比例**；若不支持，必须记录真实限制后选择获批准的分段时长，禁止谎称输出12秒、8K或使用了某个未验证模型。
4. 角色状态表与本段剧本核对：台词/口型、手持道具状态、左右顺序、动作起终、风/水/雾方向；无新增道具、无仙鹤、无外观重设计。
5. 执行 `PRE_GEN`：校验SHA、人物/道具三锚、轴线、光源、动作许可、参考图是否真实绑定模型输入、模型能力和预算；返回 PASS 才能提交一次生成请求。检查不能自动化时必须标记 MANUAL_REVIEW，不可冒充自动PASS。
6. 保留 `run_id, model_id, duration_requested, duration_actual, seed(if supported), anchor_sha256, segment_index, reference_roles, prompt_version, negative_version, cost, video_uri`；未收到模型确认不标记生成成功。

### 可复制正向锁参（每段置于剧情前）
```text
MASTER_ANCHOR_SHA256={sha}; SCENE_ID={scene}; SUB_ANCHOR_ID={optional}.
本镜头沿用已审核主基准静态帧，人物身份、五官、发型、服装和道具严格参照批准多视图和道具母图；角色左右次序、道具数量/归属/形制、陶罐/果篮/石鱼的位置与状态恒定。江心孤石、右上红日、远山、江面与晨雾保持同一物理空间；右上暖金侧逆光及阴影方向统一。机位固定在批准的180度轴同侧；只允许{静帧呼吸/极慢前推}这一种相机运动。人物仅执行{台词和微动作}，嘴唇/手指/杯具接触遵循解剖和碰撞，其他部位、服装、道具和场景结构不得自行变化。镜头首中末帧身份和空间连贯，不新增仙鹤、文字、水印或道具。
```

## 3. 分段接力与回锚
- **强制不变量：每一段均关联主基准帧；不是仅第1、4、7段才回锚。**
- **每3段附加一次强制“回锚巡检”**：第3/6/9…段结束，抽取各段首/中/末帧，逐一与主帧和角色/道具母图对照，汇总累计偏差；第4/7/10段重新验证主帧输入哈希和模型参考绑定，不能使用第3/6/9段末帧单独启动。
- 方案A（默认对白戏）：每段主帧单参考；上一段末帧仅作线下动作/剪辑对照。身份空间稳定性优先，但动作衔接要由脚本状态表与剪辑修复。
- 方案B（确有双参考能力、已实测验证且批准）：主帧强参考+上段末帧弱参考；不能保证模型对两者有可调权重，若无该能力应降级为A。弱参考绝不凌驾主帧。
- 连续动作是“场景/角色状态接力”，**不是图像漂移接力**；有动作姿态变化时新建批准的动作子基准帧，而不是强迫所有段完全回到静止姿态。

## 4. 逐段后检、量化定位与回滚
在实际视频中检查首帧、每秒关键帧、动作峰值、末帧及镜头交界；每3段另做跨段比对。仅做“三秒快检”不等于最终视觉验收。
- P0：换脸/人物左右颠倒/越轴，道具错人错数/位置漂移，红日跳边、远山重构，手指/口型/持杯严重穿帮，出现无授权仙鹤或新角色。**BLOCK，作废该段，不能把失败片末帧投入下一段**。
- P1：可见但非致命的衣纹闪烁、细微光影不连贯、杯具略微错位、镜头推速波动。退回局部修复/再审；不能仅凭口头通过。
- P2：轻微颗粒、细节噪声，允许后期修复并登记。
- 自动检查：静态源文件SHA应完全相等；**视频压缩/推镜不要求逐像素与主图相等**，改用经机位/视差补偿的关键点匹配、轨迹/分割/人脸身份人工对照。建议参考阈值仅作项目初始验收门槛：批准后静态锚点屏幕位移（扣除相机运动）≤画面对角线的1%；同镜道具相对人物手部接触漂移≤道具本体宽度的5%；红日/远山经变换对齐后的身份结构不能拓扑变化。**阈值需用真实样片标定，未部署检测器不得声称自动验证。**
- 失败流程：`FAILED → 锁定原始主帧 → 定位问题区域/帧号/根因 → 静态修复新候选/必要时审批子锚 → 重跑仅失败段 → 首中末和跨镜复审 → 合格方接力`。原失败视频保留审计但不参与继续生成。

## 5. 新镜头、新道具、新动作的变更控制
涉及仙鹤入镜、抬杯、换机位、较大表演、增加对白时，先复制主基准帧为独立静态**子基准帧**，在授权局部编辑新增内容；保留父主帧SHA、修改遮罩和目标像素变更记录，不得改写母帧。核验角色/道具一致、真实手物接触、相机在轴同侧、光照和场景资产一致后，子帧才能进入I2V。已批准的人物和道具严格按独立分层维护；整幅文本重生成不得冒充精修。

## 6. 每次出片审核交付
`manifest.json`：项目、镜头/段序号、主基准及子帧的SHA、角色多视图和法宝源图ID、道具状态、镜头轴线、运镜、模型与真实参数、成本、任务ID、前中末关键帧路径、P0/P1/P2缺陷、审核人/证据和状态。允许 `PENDING / BLOCKED / READY_FOR_USER_REVIEW / USER_APPROVED_FINAL`；用户没最终确认不得擅自标FINAL或覆盖库存图。

## 7. 江心对谈12秒开单速记
`主帧静态合格 → 三道母图+接触预检 → 绑定主帧/必要时批准子帧 → 选择12秒(实际支持才选) → 仅1个微动作+1个运镜 → 生成 → 每秒抽帧与首中末审 → 每3段额外回锚 → 通过才接下一镜`。

**注：主帧复用降低漂移风险但不能保证绝对不跑偏；真正一致性要靠资产锁定、受控输入、模型输出实测与人工/工具视觉审核共同完成。**
