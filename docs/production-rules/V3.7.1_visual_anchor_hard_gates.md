# V3.7.1 — Visual-Anchor Production Hard Gates (2026-11-12)

Applies to Eight Immortals and OneFlow production. Inherits V3.5.1 / V3.5.2 / V3.5.3 / V3.6 / V3.7.0. **No generation before approved script, prompt, actual visual references and independently checkable G3-S preflight.**

1. **Immutable identity assets**: each character, prop, environment, style has an ID, canonical image, SHA-256, approval status and frozen immutable text. Never improvise freckles, clothing, weapons, or identities or rewrite approved asset descriptions. Authorized changes require a new version.
2. **Actual visual reference binding**: image edits are preferred over uncontrolled text-to-image. A human-entered string claiming a reference was used is not proof. The adapter must provide verifiable request ID, image asset digests and reference transport evidence. Missing => BLOCK. Three-view reference sheets are useful only after director approval, not automatically authoritative.
3. **Model reproducibility metadata**: record model ID + revision, workflow revision, seed support/seed, sampling options where available, reference strength, native resolution, target resolution, mask and edit settings. Same seed is not identity lock; unsupported seed syntax or weighted prompt syntax must not be claimed to work.
4. **Strict shot schema**: unknown fields rejected; all required asset IDs from approved whitelist; physical contact, spatial anchors, continuity and script/prompt review required. No new or random actor/prop inserted. Failing reference hash, wrong version or missing reliable adapter receipt => G3-S BLOCK and **no image/video call**.
5. **Post-generation G4 and repair**: one shot/one image, compare identity, prop, clothing, water/terrain/lighting, hands and physical contact. If failure, keep approved pixels and repair localized regions when feasible, then rerun G3-S. G4 PASS + separate director approval + final image digest before promotion and video.
6. **Video**: approved still only, recommend 2–4 second clips; longer shots require project-specific validation rather than a universal unsupported hard limit. Verify video temporal consistency before release.
7. **Quality claims**: never promise "100%" identity consistency or "<10%" errors without measured evidence. 8K UHD (7680x4320) target output must be labeled interpolated where not native.

**Current S02-02 status: G3-S BLOCK.** BX04 director-approved basket concept requires an exact standalone approved reference image file + SHA binding; coast scene needs authoritative master approval; model/seed capability unknown; reference inputs not independently attested. Do not call image generation.
