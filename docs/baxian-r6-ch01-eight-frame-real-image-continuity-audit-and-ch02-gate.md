## 核心发现
1. **叙事因果**：铜铃→绳索→护灯→海底门→首浪→第二章救援是可理解的故事链；必须通过声桥与动作起止说明“石门异变导致海浪异常”，不能声称8张静帧已形成动态连续电影。
2. **场景/道具**：02与03系泊绳结、船只、背景并非锁定同一资产；07与08海堤地形、桩位、光照明显不同。
3. **人物**：04与05阿宁/小满的脸、衣着及发髻差异明显；铜灯纹样、杯口和底座不同；两图不可当同一人物同一时刻的匹配切镜。
4. **画幅**：8张近似9:16，但像素941×1670—1672；不得宣称原生8K或2160×3840。
5. **审批状态**：原图5张维持APPROVED_ORIGINAL；新增3张USER_APPROVED_VISUAL / TECH_HOLD；没有任何一张新图完成实际参考输入绑定的回执证据。
