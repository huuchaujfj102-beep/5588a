# 《八仙·大显神通》全片人物声音圣经与对白规范 R6

版本：R6.1｜日期：2026-11-22
适用：20章全片、所有文生图/图生视频/配音/补录/混音任务。
定位：史诗神话电影，不做戏曲腔、不做短视频网感配音、不用夸张方言喜剧化。

## 一、声音总原则
1. 八仙必须做到“闭眼听声可辨人”。辨识依据依次为音色、发声位置、语速/停连、句尾习惯、情绪反应，再辅以轻微口音色彩。
2. 全片以清晰普通话为可懂度基准；地域韵味只做轻度表演色彩，不把任何角色写成无法听懂的方言。下列口音方向是创作表演设定，不是对角色历史籍贯的考证。
3. 同一角色的声线不可随章节漂移。战斗、悲伤、愤怒只改变力度、气息和节奏，不改变基本音色。
4. 台词必须推动人物、关系或行动。禁止解释观众已经看到的动作；禁止八个人轮流喊同一句口号；禁止每句都用“妖孽/受死”等空泛套话。
5. 群战对白遵守指挥层级：吕洞宾给策略指令；各仙只报告自己观察到的事实/执行动作；不得多人同时抢话。
6. 配音必须与嘴型、呼吸、身体动作匹配。远景不强制清晰口型；近景对白必须有对应口型与呼吸节奏。画外音不能冒充现场对白。

## 二、八仙声音角色卡

### 1. 铁拐李｜粗粝、沉稳、带伤者的厚重气
- 音色：中低音，胸腔共鸣明显，略带砂砾感；不是虚弱老人声。
- 口音色彩：北方中原韵味轻点到为止，字头结实，卷舌适度。
- 语速：中慢，句子短，先说判断再下动作命令。
- 句尾：常收住，不拖长；关切时声音压低，不突然变甜。
- 情绪：护人时厚实可靠；受挫时压着火；发怒不咆哮，像压住一口气。
- 避免：全程喘、全程沙哑、滑稽口音、跛足被演成口齿不清。
- 台词样例：「先扶伤者上来。浪还没退，别急着往前冲。」

### 2. 汉钟离｜宽厚、开阔、松弛中有威势
- 音色：中低音偏暖，气息宽，胸腔共鸣圆润。
- 口音色彩：关中/西北韵味极轻，开口有力度，不能做浓重地方腔。
- 语速：中速，转折清楚；平时略带从容，危急时突然简短。
- 句尾：下沉、稳，不飘；安慰人时留一点气口。
- 情绪：平和时像长者；战斗时声音打开、有风压感；不轻浮。
- 避免：酒醉腔、喜剧式大嗓门、每句都像训人。
- 台词样例：「扇开一线，够他们过去。后面的浪，我来挡。」

### 3. 吕洞宾｜清正、锋利、克制的领袖声线
- 音色：中音偏清亮，咬字清晰，发声位置靠前，剑一样干净。
- 口音色彩：接近标准官话，少量文雅韵律，不用戏曲念白。
- 语速：中快，逻辑句层次清楚；下令时更短更准。
- 句尾：干净收束，少拖音；思考时句间留白。
- 情绪：坚定但不傲慢；犯错后声音会沉下来，不推卸责任。
- 避免：播音主持腔、全程高冷、每句话都像古文。
- 台词样例：「先救人。剑若护不住眼前的人，出鞘又有何用？」

### 4. 蓝采和｜灵动、清透、带一点少年气
- 音色：中高音，轻而不薄，吐字灵巧，气息有弹性。
- 口音色彩：江淮/江南轻软韵味，少量柔化字尾；普通话清晰优先。
- 语速：中快，转折灵活；安抚时放慢，行动时节奏变快。
- 句尾：略带上扬但不撒娇；坚定时突然落稳。
- 情绪：善意、机敏、乐观；面对牺牲时不轻佻。
- 避免：娃娃音、嗲声、搞笑少年腔。
- 台词样例：「藤桥接上了！一个一个来，别踩着前面的人。」

### 5. 张果老｜苍劲、幽默感藏在停顿里
- 音色：年长男性中低音，略干、略旧，气息沉长；不能虚弱。
- 口音色彩：晋冀老派语音节奏，字音稳，语尾略有古朴感，不做方言段子。
- 语速：偏慢，善用停顿；观察时像在听回声。
- 句尾：偶尔带轻微反问或含蓄笑意；危急时没有玩笑。
- 情绪：平日有洞察与淡淡风趣；关键时刻沉着坚定。
- 避免：纯老年喘音、故意装糊涂、戏谑灾民。
- 台词样例：「听潮，不听浪。浪会骗人，回声不会。」

### 6. 韩湘子｜温润、专注、清雅的气息声
- 音色：中高音偏柔，清澈、轻气声但有支撑；不娘、不虚。
- 口音色彩：江南吴语韵味只体现在轻柔连读和尾音，不使用听不懂的方言词。
- 语速：中慢，句子有旋律感；吹笛前先吸气，讲话也保留呼吸节拍。
- 句尾：轻收，不拖长；看见真相时语气清晰而坚定。
- 情绪：温柔但有判断力；危机中不慌。
- 避免：唱腔、吟诗腔、全程耳语。
- 台词样例：「笛声里有两道回响。左边是幻潮，右边才有礁脊。」

### 7. 何仙姑｜清澈、端正、温柔里有决断
- 音色：中高音清透，气息稳定，字音圆润但不甜腻。
- 口音色彩：岭南清润韵味轻微，普通话清楚；避免明显粤语腔导致跳戏。
- 语速：中速，安抚伤者时舒缓；下决断时语速收紧。
- 句尾：柔和落点，不飘；拒绝/坚持时干脆。
- 情绪：慈悲不是软弱；救援时坚定，受压时不尖叫。
- 避免：仙女嗲音、过度气声、哭腔常态化。
- 台词样例：「莲台只能载这一程。先把孩子送到岸上，再回去接人。」

### 8. 曹国舅｜端方、礼制感、克制的权威
- 音色：中音偏厚，清晰、端正，气息控制严格。
- 口音色彩：标准官话带旧式京腔节奏，咬字规整，不用官腔套话。
- 语速：中慢，句法完整；下令时句子更短。
- 句尾：平稳下压，几乎不拖音；愤怒时反而更轻。
- 情绪：讲原则、守秩序，但必须能承认错误；不冷酷。
- 避免：现代官员腔、播音腔、居高临下。
- 台词样例：「护壁不能封死退路。留一道缺口，让百姓先行。」

## 三、四王、太子、沧汐、玄溟声音卡
- 东海龙王：低沉、老练、威严，语速慢，像在权衡全局；认错时不找借口。
- 南海龙王：中低音、果断、火气较显，句子短，容易先下判断后补解释。
- 西海龙王：音色冷静、清晰，偏分析型，停顿少；发现龙息被吸取时第一次出现迟疑。
- 北海龙王：厚重、谨慎，语速较慢，重视边界与后果。
- 龙太子：年轻中低音，锐利、纪律性强；前期执行命令不轻佻，后期意识到误伤百姓时声音出现裂痕。
- 沧汐：清冷但有温度，声音像长久独处后重新学习与人交流；前期记忆缺口体现为迟疑和词语搜索，不是痴呆/完全失忆；归印时坚定、清楚。
- 玄溟：非普通反派腔。低频、近距离、气息不稳定，像从潮汐/裂隙中传来；不靠持续大吼。诱导幻象时轻声贴近，失去裂隙支撑时声音逐渐失去空间回响。

## 四、对白与声音连续性执行规则
- 每句对白登记：角色ID、文本、情绪、音量、语速、口音强度（0—3）、发声距离、是否画内、起止时间、口型/呼吸动作。
- 口音强度：0=标准普通话；1=仅韵律/个别字音色彩；2=可辨地域韵味但完全可懂；3=仅极少特定情境使用。八仙常态建议1，绝不把角色全片固定在3。
- 同一场景环境声连续；人物换镜时对白不得无故重叠。动作台词要留出喘息、出招、受力和反应空间。
- 群像对白按“主指令—执行回应—结果反馈”排布，不让八仙齐声喊口号。
- 不把背景音乐压在对白核心频段；关键命令前可短暂让音乐退让。
- 每章至少有一段不靠对白、只靠表情/动作/环境声推进的情绪段，避免人物不停解释剧情。

## 五、对白验收
1. 盲听八仙单句，至少能凭音色/节奏区分角色；若两人混淆，先调整声线与节奏，不靠加重方言解决。
2. 近景口型与台词音节同步；爆发音、喘息、停顿和动作接触点一致。
3. 同角色跨章音色稳定；不得第1章厚重、第10章突然变少年音。
4. 角色台词不能互换；把一句台词交给另一仙仍完全成立，说明人物辨识不足，必须重写。
5. 史诗感来自控制、节奏、空间和表演层次，不来自全员提高音量。

## R6.3新增龙宫群像声线

- 东海龙王：四王中最低沉、胸腔宽、老练威严；慢速权衡，认错时不辩解。
- 南海龙王：中低音硬朗、火气较显；短句快起快收，前期强硬、后期承认急躁。
- 西海龙王：冷静清晰、分析型；中速偏快，发现龙息反控时首次出现停顿。
- 北海龙王：厚重谨慎、语速慢；重视禁界后果与风险。
- 龙太子：年轻中低音、锐利纪律性强；前期军令短促，后期迟疑与愧疚显现。
- 表兄甲：中音偏亮、咬字干净、军纪型；服从命令、维护阵列。
- 表兄乙：中音略柔、尾音稍缓、观察型；先注意受困百姓，较早产生疑问。
- 虾兵：年轻中音、轻而略急；前线传讯、容易紧张，不能全体同声。
- 蟹将：粗厚中低音、短促务实；负责阵型、兵器与基层口令。
- 龟丞相：老年中低音略沙、吐字稳、慢而谨慎；熟悉海禁旧制，是证据报告者和制度传令者，不是战场吼将。

口音均为轻度表演色彩，普通话清晰优先。表兄甲/乙为临时工作称呼；若已有正式角色姓名，必须以项目既有设定替换。新增角色声线需要独立试音与盲听辨识，不得与八仙或四王混音同质化。
