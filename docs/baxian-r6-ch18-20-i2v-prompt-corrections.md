## 2. 第18章：两处提示词必须按“前镜实际尾帧→本镜目标图”重写

### F16-X05｜金翼掀海，八仙落水

实物帧：095_F16-06为八仙迎翼承压、尚未完成落水的前镜状态；096_F16-X05图已经呈现八仙落水后的海面状态，八仙与白驴均在浪中/浪边，部分人物已抓住法器或借莲台承托。

原ZIP提示词同时写“3–7秒八仙先后入水”与“从已落海位置延续漂浮”，互相冲突；140任务JSON的script_start_state“受冲击离原支撑”与allowed_forward_action“从已落海位置延续”也不一致。

**R6统一动作：**
- 起点只取上一镜F16-06生成并验收的真实尾帧095；不得把096落水结果图当成动作起点。
- 096_F16-X05只作目标姿态/构图/落水分布参考。
- 0–1秒：延续翼压水墙的惯性，八仙重心离开礁面。
- 1–5秒：按画面可见人物逐一完成入水，落点分散但浪向统一；不要求所有人同一帧入水。
- 5–7秒：只保留入水后的第一轮浮力反应、抓稳原法器、互相辨认；尾帧接近096的既有落水状态。
- 不允许从已落水状态重新起跳/再落一次；不得额外增加画外人物；白驴只按参考中可见状态保留，不凭空消失或增殖。

**修订正向提示词：**

“从上一镜F16-06实际验收尾帧开始，延续金翼下压造成的同一股水墙与八仙离开支撑的惯性。八仙按各自可见位置先后失去礁面支撑，沿同一浪向落入海中，落水次序有先后、落点可辨；先接触水面再出现水花与身体浮力反应。后半段只做落水后的短暂挣扎、抓牢原法器、辨认同伴，最终姿态匹配096_F16-X05。096只作为落水结果参考，不作为本镜起始姿态。保持八仙身份、服装、原法器和白驴数量；不重演已经发生的翼压，不从落水结果倒回礁上，不出现第九仙或重复落水。”

### F16-R01｜莲台接应韩湘子、曹国舅

实物帧：098_F16-R01已经呈现何仙姑莲台承托三人、曹国舅站在莲台上、韩湘子在莲台边缘受何仙姑拉扶的中间状态。它不是“韩曹仍在浪中、莲台尚未靠近”的纯起始图。

原ZIP写“0–2莲台靠近、2–7接应”，又写“莲台已经接住韩曹、二人只收腿坐稳”；140任务JSON也同时写“韩曹仍在浪中”与“已经接住”。必须固定一套首尾帧角色。

**R6统一动作：**
- 起点使用F16-X06实际验收尾帧（浪中互助/抓礁状态）。
- 098_F16-R01作为接应结果和姿态参考，不当作尚未接触的起始图。
- 莲台从既有浪中救援位置靠近，何仙姑伸手接住韩湘子；曹国舅先在莲台上稳住身形，白玉板、青玉板仍各一块、仍归其主。
- 韩湘子从浪中被拉扶到莲台边缘，双脚/膝部接触莲台后才转移重心；何仙姑承重姿势与莲台浮力同步变化。
- 末帧匹配098：曹国舅已被莲台承托，韩湘子仍处于何仙姑拉扶下的稳定过渡姿态；不强行让所有人站成定格合影。
- 不再演一次莲台从远处飞来，不把已经发生的接触倒演，不让笛、双玉板易主或复制。

**修订正向提示词：**

“从F16-X06上一镜实际尾帧的浪中互助状态接入。何仙姑操控同一巨型莲台沿浪面靠近，莲台先稳定在韩湘子与曹国舅身侧；曹国舅先借莲台承托稳住身体，手中白玉板与青玉板各一块；何仙姑伸手拉扶韩湘子，韩湘子沿水面向莲台边缘转移，接触莲台后再收腿、移重心。莲台随三人重量产生轻微下沉后回稳，最终停在098_F16-R01所示接应姿态。不要从已接住状态重新演靠近，不要让韩曹瞬移上台，不增加第三块玉板，不改变韩湘子横笛。”

## 3. 第19章：F17-X19a是真正的缺图补拍任务；F17-X19只能做海水回落

### 3.1 F17-X19的G03-04状态

F17-X19绑定的G03-04为已批准锁定资产，审批依据为用户“30张过”。已从第38段ZIP抽取121_F17-X19.png查看：画面主体是黑潮/海水形成的巨大漩涡与海眼，**没有可辨认的玄溟头肩或人物形体**。因此它可以做海水向归墟回落的结果镜，不能让提示词要求它从画面中不存在的玄溟头肩继续内坍。

### 3.2 F17-X19a任务缺口

第38段ZIP有NEW_PROMPTS/06_F17-X19a_4s.txt，分镜表也列出F17-X19a“玄溟潮核内坍（补拍镜）”，但ZIP中没有106_F17-X19a.png，140任务JSON的140条jobs中也没有独立F17-X19a任务。它是一个有提示词、无正式首帧、无独立任务映射的孤立补拍镜。

**R6修正：**
- F17-X19a必须补一张经过审批的玄溟潮核内坍关键帧，并正式加入任务映射，明确其在R5-E08之后、F17-X19之前。
- F17-X19a只负责玄溟水影头肩失形、黑潮丝束向唯一海眼内坍；青玉方印已留槽、八宝仍在阵中，不向外爆炸。
- F17-X19使用已批准G03-04/121水漩涡图，只负责海水从原方向开始回落并沿同一海眼退向归墟；不再描写玄溟头肩或黑潮主体形变。
- 若暂时不补F17-X19a关键帧，不能把它当作已生成任务；可将4秒画面暂时留空，用归印后的内吸声桥接至F17-X19海水结果镜，但必须把“玄溟内坍可视化”标为未完成，不得宣称故事视觉因果已经完整。

**F17-X19修订正向提示词：**

“以已批准121_F17-X19水漩涡图为唯一输入，画面只表现已经断源后的海水结果。沿现有漩涡中心和原水流方向，外围浪脊逐步向唯一海眼回落，水位降低、回流变缓，岸线和礁石位置不变。青玉方印留在旧槽，八宝仍在阵中但不强行补画。不得生成玄溟头部、肩部、人体轮廓或新的黑潮怪物；不得向外爆炸，不得重建海岸，不得重复归印。”

## 4. F17-06与F17-C04：C04是控制锚点，不是独立生成镜头

140任务JSON明确F17-C04的mode为CONTROL_ANCHOR_NOT_AUTOMATIC_STANDALONE；ZIP也把123_F17-C04.png作为F17-06的解体中间控制帧。故不能把F17-C04当作一条额外独立视频任务。

- F17-06输入122_F17-06完整金龙图，目标控制姿态为123_F17-C04四王显形、上空保留透光金翼胸廓粒子残影。
- F17-06必须在本条视频内完成“阵纹压住余波→金龙失去潮脉共振→金龙实体逐步粒子化→四股金流沿各自原轨迹回归四王”的连续过程；不得瞬间消失，也不得四王与完整金龙重复叠加。
- 123_F17-C04只用于控制中间/尾部姿态，不另生成一条视频。
- F17-07从四王已经显形的状态继续，完成金粒余光散尽、四王站稳与低眼收肩；不得再次从完整金龙开始变形。
- ZIP当前F17-06提示词写“金龙粒子化分四股原方向返回”，方向正确，但需把“渐进过程”和“最终匹配123控制帧”写清；140任务JSON里“本段不直接凭空消失”应解释为不得瞬间消失，而非把解体动作全部推给不存在的独立C04视频。

**修订正向提示词：**

“从122_F17-06唯一金龙实体状态开始，八宝阵纹继续压住归墟余波，金龙胸腹与翼根先失去潮脉共振，鳞片边缘逐层化为金粒，四足、双翼和长尾依次失去实体支撑。金粒不是爆炸，而是沿青、赤、白、黑四王原本对应的四条潮脉轨迹回流；四王逐一显形，空中只留下123_F17-C04所示透光金翼胸廓残影。最终匹配123控制帧，不出现第五条龙、不保留完整金龙实体与四王双份叠加。F17-07再继续四王站稳与余光散尽。”

## 5. 第20章：F18-C01是控制起势帧，F18-X20才是唯一点灯视频

实物帧核验：
- 134_F18-C01：母子在灯前，小满持有带火焰的木火引，灯芯仍未燃；阿宁护着小满的手。
- 135_F18-X20：同一铜灯已经点燃，阿宁的手覆在小满手上，属于点灯后的情绪结果帧。

140任务JSON将F18-C01标为CONTROL_ANCHOR_NOT_AUTOMATIC_STANDALONE，F18-X20为SHOT_CLIP_DESIGN。第40段ZIP的F18-X20提示词也明确把134作为未燃起势首帧、135作为点亮后的结果参考。因此：
- F18-C01不单独生成视频。
- F18-X20作为唯一视频任务，从134未燃状态到135已燃状态，完成木火引靠近、火焰接触灯芯、灯芯被点燃、火引退出、阿宁覆手和母子松气。
- 不得把F18-X20提示词改成“只做覆手”，否则会丢失点灯动作；也不得另做一条C01点灯视频再把X20重复点燃。
- 140任务JSON里F18-X20的allowed_forward_action“从铜灯已经燃稳的结果图开始，只让母亲轻覆孩子手”与ZIP提示词/分镜表的起止帧不一致，R6应以134→135的控制帧关系为准修正该字段。

**修订正向提示词：**

“以134_F18-C01未燃灯芯状态作为起势，以135_F18-X20已燃灯状态作为结果姿态参考。小满手持同一根带火木火引，沿原手臂方向缓慢靠近莲纹铜灯灯芯；火引火焰必须实际接触灯芯，灯芯受热后才由暗转亮，火焰稳定后木火引才缓慢退出。阿宁始终护住小满手腕，待灯芯站稳后才把手轻覆在小满手上，母子呼吸放松。全过程只出现一盏铜灯、一根木火引；不得灯芯自燃、不得现代打火机、不得第二根火引、不得先亮后熄再点。”
