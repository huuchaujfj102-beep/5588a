# 生图与生视频穿帮防控：增补规则

本文件只补充已有七模块导演提示词、连续性约束和人工审核门禁缺少的细则；既有流程见 [OneFlow](oneflow.md) 和 [GLM文本审核](glm-runpod.md)。

## 接入范围与使用约定

- 共享规则集中于 `oneflow/continuity_rules.py`，生图 `build_prompt`、分镜生图 `prompt_from_request`、视频 `film_prompt` 和可选抽帧审核复用该模块。ComfyUI参数映射复用共享负面词，不增加未经确认的供应商字段。
- HF、fal、Cloudflare、OVH入口通过现有共享生图构建函数获得正面约束；未独立修改它们的协议、尺寸上限或付费确认。
- 原生千帆车辆I2V、Vidu直接传入的提示词、Remotion剪辑尚未自动接入本模块；使用者按本文正面/负面模块编排，不能宣称所有入口已自动执行。
- 沿用既有七模块：原图锁定、局部微动、环境动态、一次慢速运镜、光影、输出、负面约束，不另建重复流程。
- 神通白名单由本次用户设定决定：踏云、御空、仙山悬浮、花瓣漂浮、四季共生均可允许。禁止无解释的脱手、悬空和变形，不全局禁止漂浮或形变。
- 正常透视、遮挡、反射与景深随机位变化不算穿帮；负面词按画面选择，不能代替正面结构要求或审片。
- 独立负面字段以现有适配器支持为准；没有该字段时写入主提示词。Remotion使用素材校验与时间线/成片检查，不假设存在模型负面提示栏。
- 8K/UE5等风格要求不等于实际分辨率或渲染器验收。

## 2. 道具穿帮清单

高频：静态图；视频还需核对帧间一致性。

### 结构与数量

物体数量错乱、数量忽多忽少、物体缺件、零件凭空消失、物体凭空多出、部件错位、部件无依托悬浮、零件漂浮、物件异常拆分、物件拼接畸形、物件断裂错位、重复道具不一致、同款道具细节不一样、道具尺寸忽大忽小、比例崩坏、大小跳变。

### 结构逻辑

道具无支撑且无神通解释的悬浮、道具穿插墙体或人体、道具穿模、物体互相穿透、把手正反错乱、开关方向反、卡扣错位、接口对不上、容器没有底、容器漏底、器皿结构矛盾、家具榫卯错误、工具结构不合理、武器结构崩坏、武器刃口扭曲、武器部件错位。

### 细节纹理

纹理错乱、贴图拉伸、纹理重复错位、logo扭曲变形、文字镜像、文字乱码、文字反转、文字笔画错乱、标识方向错误、刻度错乱、刻度数字不对、花纹错位、印花撕裂、材质贴图跑位。

### 视频专项

道具帧间跳变、道具非设定形变闪烁、道具瞬移、道具位置漂移、上一帧有下一帧无故消失、道具自动变换款式、手持道具脱手悬浮、道具抖动畸变、反光无因闪断。

## 3. 场景画面细微穿帮清单

静态检查结构、透视与遮挡；视频增加前后状态比对。

### 环境结构

空间逻辑矛盾、空间透视冲突、透视错乱、两点透视崩坏、三点透视错误、地面高低突变、地面接缝错位、地砖纹理错位、地板拼接断层、墙面接缝撕裂、墙体穿插、墙体厚度异常、门窗位置矛盾、门窗尺寸忽变、门洞错位、天花板结构错乱、梁柱穿插、台阶步数前后不一致、台阶高度错乱、道路走向矛盾、无设定的道路断头、路面断层。

### 环境元素

植被形态跳变、树木轮廓闪烁、树叶无因增减、花瓣瞬移、水面形态突变、水面倒影错乱、应见倒影丢失、倒影变形扭曲、倒影和实物对不上、影子形状突变、影子数量不对、影子方向混乱、远处景物凭空增减、远景建筑错位、建筑楼层数量变化、建筑结构前后不一致。

### 隐性杂物

电线悬浮、电线无端点、管线穿插、护栏杆件数量错乱、栏杆空隙忽大忽小、栅栏错位、地砖砖缝错位、青苔位置跳变、污渍位置变化、墙面斑驳纹理帧间变动、地面水渍忽有忽无。

## 4. 光影与材质穿帮清单

静态与动态均检查；不能把合理的多光源、曝光变化、反射变化误判为穿帮。

光源方向与设定冲突、多光源关系矛盾、光源位置无因跳变、光照强度无因忽明忽暗、局部打光跳变、丁达尔光断层、光束形状突变、应见反光消失、反光位置与几何关系不符、镜面反射穿帮、镜面出现无对应来源的物体、高光闪烁、高光无因漂移、PBR材质无因跳变、金属反光忽强忽弱、磨砂质感无因切换、玻璃通透度跳变、焦散错乱、阴影闪烁、软阴影无因变硬阴影、阴影边缘跳变、阴影与遮挡物关系不符。

## 5. 人物交互与接触穿帮清单

静态高频，动态为重点。

物体接触穿帮、手没有握住道具、手指穿插道具、手掌穿透物体、指尖与接触面无因分离、抓握姿态悬空、脚踩空、脚部穿透地面、接触阴影缺失或位置矛盾、衣物穿插道具、布料穿模、布料和物体互相穿透、饰品穿插皮肤、配饰无依托悬浮、腰带或飘带连接点缺失、发丝穿插物体、发丝穿插皮肤。

补充判定：检查肩—肘—腕—手及髋—膝—踝—脚的连接。遮挡造成看不全不等于缺失；无法判断时标“待核查”，不得编造多指、断肢或穿模结论。走路的脚跟着地、前脚掌支撑、正常抬脚不自动判为踩空。

## 6. 镜头时序与运镜连贯穿帮清单

视频专项。

镜头内非设定空间跳切、镜头移动时景物畸变、慢推镜头景物撕裂、运镜透视漂移、机位逻辑冲突、前后镜头空间不连贯、同一场景无因色调跳变、色温跳变、饱和度闪烁、画幅元素突变、景深无因跳变、焦点乱跳、虚化范围无因忽大忽小。

| 运镜 | 正面约束 | 必查项 |
| --- | --- | --- |
| Slow Push-in 慢推 | 单次低速连续推进，主体结构与相对位置稳定 | 背景层级与视差、门窗比例、纹理稳定、对焦渐变 |
| 横移 | 机位连续侧移，近远景视差与遮挡顺序合理 | 栏杆与柱数、道路连续、背景补全、物体无拖影复制 |
| 环绕 | 按约定方向与幅度连续转动，角色与道具三维结构一致 | 背面结构、握持点、剑鞘轴线、遮挡再显露、光影随视角合理变化 |

动态补充：脚底滑移、接触点漂移、承重切换错误、运动速度无因突变、动作回跳、衣摆与发丝闪烁、同一物体遮挡后变款、已升空主体无过渡回地面、车辆行驶方向无因反转。不得为了稳定性把正常轮转、流水或风动纹理一概冻结。

## 7. 可直接选用的提示词模块

### 正面基础约束

人物与道具数量明确且一致，完整合理的结构与比例，部件连接清楚，握持和支撑可信，接触点与遮挡关系正确；建筑与道路空间连续，透视一致；纹理附着表面，主辅光源和反射、阴影关系合理；人物、关键法器及必要的脚部完整入镜，边缘留出空间。神通效果严格按当前设定呈现，不改变主体结构。

### 静态基础负面词

穿模,物体互相穿透,道具缺件,道具异常增殖,部件错位,部件无依托悬空,物件断裂拼接,比例异常,文字乱码,文字镜像,标识反转,透视错乱,空间矛盾,倒影与实物不符,阴影与光源矛盾,手穿道具,错误抓握,脚部穿地,布料穿模,发丝穿入物体,连接点缺失,纹理拉伸,关键道具意外出框

### 视频追加正面约束

锁定原图人物身份、服饰、道具数量、款式、比例和连接点；仅执行约定动作与一次低速运镜。接触点随动作正确移动，受力与支撑连续，遮挡前后结构保持一致。景物视差、反射、阴影和景深随机位自然变化，帧间连续，镜头间状态承接。

### 视频追加负面词

帧间结构跳变,无因形变,道具瞬移,道具位置漂移,道具凭空消失或增殖,遮挡后变款,手持道具脱手,接触点漂移,脚底滑移,动作回跳,背景闪烁,纹理爬动,建筑结构突变,反光无因闪断,阴影闪烁,运镜景物撕裂,透视无因漂移,焦点乱跳,景深突变,色温跳变,色调闪烁,无过渡空间跳切

### 质检检索词

穿帮、穿模、无因悬浮、瞬移、闪烁、跳变、错位、穿插、穿透、倒影、影子、光源、透视、道具数量、文字镜像、台阶、地砖、抓握悬空、接触点、轴线、连接点、遮挡再显露。

说明：这些检索词用于查找已经形成的审片记录、字幕/OCR文本或检测报告；Ctrl+F不能直接检测视频画面中的穿帮。

## 8. 已发生问题的专用约束

| 对象 | 必须写入正面提示词 | 重点禁止 |
| --- | --- | --- |
| 吕洞宾背剑 | 一把入鞘长剑，柄—护手—鞘口—鞘身在同一直轴，背带固定；隐藏段不强求露出 | 肩上与腰侧剑鞘错轴、断段拼接、剑穿躯干、重复长剑 |
| 拂尘 | 一根连续柄，一端固定尘丝，手握无毛柄段，另一端为清楚裸柄尾 | 两端出毛、尘丝起点错乱、柄穿手、尘丝与胡须融合 |
| 蓝采和花篮 | 单篮单拱柄，两端固定篮沿；一手握柄、一手托底，指尖轮廓清楚 | 篮柄断接、手与竹编融合、篮底缺失、支撑无解释 |
| 蓝采和四季花旋 | 主藤从篮内连续长出，季节花群沿主藤分层，面部无遮挡 | 悬空断枝、顶部枝条与花篮断开、误把背景树枝接入花旋 |
| 张果老仙驴 | 驴头与骑者胸口方向相反，腿跨驴身合理；一人一驴、四肢清晰；踏云列入神通设定 | 正骑冒充倒骑、腿与坐骑融合、驴变马、肢体增殖 |
| 巨葫芦/巨扇/巨莲 | 明确相对人物比例，完整法器轮廓、合理握持与支撑；巨物需拉远取景 | 只放大特效未放大道具、边缘意外裁断、杆柄断接 |

## 11. 质检分级与记录

| 等级 | 示例 | 处理 |
| --- | --- | --- |
| 阻断 | 多余肢体、道具断接、剑身错轴、穿体、关键物体增减、场景或动作状态突变 | 不作为定稿，不进入正式发布；修复后复检 |
| 待修 | 指尖融合、支撑不清、关键边缘裁切、明显反射/阴影矛盾、持续闪烁 | 指出位置与依据，修复后复检 |
| 风格建议 | 合理但不理想的留白、衣摆、饱和度、特效强度 | 作为建议，不冒充结构错误 |
| 待核查 | 遮挡或清晰度不足，证据无法支持结论 | 标记不确定，不宣称已通过 |

审查记录字段：素材名与版本、图片区域或视频时间码、问题类别、可见证据、确定程度、严重程度、修改约束、复检状态。

定稿规则：所有阻断项和待修项解决；未覆盖范围与待核查项明确说明。审片记录不夸大检查覆盖度，不承诺绝对零穿帮。
