1. 输入预检：shot_id、唯一时刻、画幅、景别、可见人数、人物ID、批准母图文件/哈希、场景母图/来源链、法器数量/归属/左右手/握点、朝向/视线、前后镜状态。

3. 提示词编译：使用V2.3正面结构+V3.5.4真人电影摄影核心+本镜相关负面约束；清除互相冲突的CG游戏感/实拍风格词；不得将8K、镜头焦段等文字当作实际输出参数。
4. Dry-run：核查最终prompt、负面约束实际传递方式、字符限制、模型接口schema；不得截断用户原文；未验证适配器时不宣称编译器已在fal运行时生效。
5. 单张生成：每次只生成一个shot候选，不做16张拼图/角色拼盘；记录模型、endpoint、完整最终prompt、实际参考输入、输出尺寸、文件哈希和费用记录。
6. 全图与100%原尺寸局部审查：A身份；B人数/物种；C姿态/承托；D法器结构；E握持；F视线/轴线；G光源；H材质/皮肤；I背景物理；J光学观感；K画幅/像素；L相邻镜连续性。每项PASS/FAIL/NEEDS_EVIDENCE/NA并写区域证据。
