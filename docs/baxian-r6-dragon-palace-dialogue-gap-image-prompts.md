# 《八仙·大显神通》龙宫群像对白补缺镜头与图生视频提示词 R6.3

版本：R6.3｜2026-11-22  
分支：`baxian-r6-story-rebuild`  
目标：补足四海龙王、龙太子、双表兄、虾兵蟹将、龟丞相的角色对白承载镜头；为后续静帧补图、图生视频和配音做好准备。

## 0. 使用边界与制作规则

1. 下列 `GAP08-xx` 至 `GAP19-xx` 是**建议新增镜头ID**，尚未写入原始140镜头映射表；补图审核通过后再正式并入映射表，不能冒充已存在镜头。
2. 现有已批准关键帧不重绘、不替换。新提示词只补目前缺少的说话反应、角色关系、军令传递、龙族内部争执和认错承接画面。
3. 不给龙王/龙族角色增加未经设定的新法器、旗帜、徽章或随身物。服装、鳞甲、冠饰按已批准角色参考图锁定；若参考图未提供，先做角色设定审核，不凭空锁定细节。
4. 四王必须有四种可辨声音和不同决策立场；不能四个人轮流重复同一条“封海”台词。
5. 龙太子与双表兄是三种不同人物：太子负责传令并承受父王命令；表兄甲更重视军纪；表兄乙更早注意到船民和黑潮证据之间的矛盾。表兄甲/乙为暂用工作称呼，若项目已有正式姓名，以既有设定替换。
6. 虾兵、蟹将不是一群同声配音的杂兵。虾兵偏年轻、机敏、容易紧张；蟹将偏粗厚、务实、重阵型。龟丞相是老成、谨慎、熟悉海禁旧制的文职谋臣，不是战场吼将。
7. 所有图生视频提示词要求：保持角色身份、面部、甲胄、身体比例、方位、手部状态、现有道具一致；无角色变脸、无新增人物、无武器复制、无字幕、水印、现代口型夸张。口型只给当前发声者，其他人做自然聆听反应。
8. 图像提示词用于补静帧，不保证自动生成准确对白或口型。建议先生成静帧并审核构图/角色，再以该帧作为I2V起始帧；台词由独立配音轨控制，视频模型只负责自然口型与表演辅助。

| 表兄乙（观察型） | 中音略柔、尾音稍缓 | 中慢、先观察后发问 | 最早看见百姓受困、开始质疑 |
| 虾兵 | 年轻中音、轻、略急 | 偏快、句尾上扬 | 前线传讯、惊慌反应、被救后变化 |

口音均为轻微表演色彩，强度0—3建议常态1；普通话清晰度优先。四王不可通过单纯音高区分，必须同时区分音色、停连、句式与立场。

## 2. 新增补图镜头与图生视频任务

每个镜头均提供“静帧图像提示词”和“I2V动作/对白提示词”。推荐时长仅为制作规划值，需按最终动作和台词实测调整。

### GAP08-01｜四王首次分别亮相（建议接F07-03）
**补缺目的：** 现有四王同框不足以承载四种独立立场与声音，需有可剪辑的单人/双人反应镜头。

**静帧图像提示词：**  
16:9电影宽银幕构图，承接已批准四海龙王角色参考图，四王在海禁阵前按既定位置分层站立，东海龙王处于主位，南海龙王略向前、西海龙王观察海面潮纹、北海龙王注视禁界边缘。四人面部、冠饰、鳞甲、身材比例完全遵照各自参考图，不互换服饰，不复制脸型。海面有受污染救援船尾流的黑潮痕迹，远处封海柱压住潮线。UE5级写实电影CG、PBR鳞甲与布料、真实海雾、冷暖对比照明、面部细节清晰、8K质感、无文字无水印。

**I2V动作/对白提示词：**  
镜头缓慢横移，依次给东海、南海、西海、北海龙王各一个短反应，不让四人同时开口。先由东海龙王微抬眼、缓慢开口；南海龙王下颌绷紧；西海龙王视线追踪船尾黑潮；北海龙王望向禁界线。只有东海龙王口型运动，其余人物闭口聆听。禁止面部漂移、嘴部夸张、冠饰变形、人物换位。建议5—7秒。

**对白：**
- 东海龙王：「船尾的黑潮，已经贴上禁界了。此事不能轻断。」
- 南海龙王（切反应镜/不与东海抢话）：「再迟一步，整条海线都要失守。」
- 西海龙王（独立近景）：「黑潮在随船移动，不是海面自然回流。」
- 北海龙王（独立近景）：「若污染入界，旧封印承受不住。」
