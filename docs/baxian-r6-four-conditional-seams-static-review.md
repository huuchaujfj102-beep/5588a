# R6 四条条件式尾帧接续静态对照复核

日期：2026-11-22  
范围：R5-C090、C093、C113、C118。  
依据：第35—38段ZIP中的原始批准PNG；只做静态构图/空间/道具状态对照，不代表视频动态验收。

## 结论

四条边全部继续保持CONDITIONAL_TAIL_CONTINUATION。静态图只能说明是否存在接续可能，不能证明真实视频尾帧与下一镜首帧兼容。所有四条均未生成视频、未取得真实尾帧、未动态PASS。

## 统一放行条件

1. 前一镜真实生成视频先通过正常速度与关键动作逐帧检查。
2. 抽取验收尾PNG，登记帧号、PTS、SHA-256。
3. 与下一镜首帧逐项比较机位、景别、尺度、地平线、人物位置、道具位置、运动方向、速度、光线和动作相位。
4. 兼容才允许用实际尾帧续生；不兼容时改为有动机的剪辑切换或补动作桥，不得用光流/叠化掩盖。
5. 当前四条真实尾帧均不存在，故状态仍为NOT_GENERATED_NOT_REVIEWED / CONDITIONAL。
