## 先做什么

1. 先查回S01-01、S01-02、S02-03、S02-04、S03-01已有的获批满幅竖图。不得用模糊竖底和站位预演直接进入正式视频。

3. 统一凡人角色与铜灯的剧情引用；面海群像保持锁定，另核片尾动作位置。
4. S08-01、S11-02先补沧汐资产依据。
5. 无上述阻断且局部准入完成后，优先S04-03做单人刚性扇、S06-03做法术水面、最新面海群像做八人微动的3类验证。每类需真实输入与输出复核，当前未调用视频模型。

## 不确定项处理

- 神通允许悬剑、莲台浮水等设定，不把悬浮本身误判为穿帮。
- 村庄换到另一画面侧可能是合理换机位，缺落位依据时记待核，不武断断定全镜错误。
- 画面为近景时，下裁切不等于缺腿；遮挡不可见部位不编造正常或异常。
- 本轮未逐像素配准、未测光向角度/水位高度、未声称视频已经顺接。
