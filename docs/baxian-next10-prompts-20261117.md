# 八仙｜下十张专业关键词精修 R2

日期：2026-11-17（北京时间）。范围：DB-10-01—DB-10-07、DB-11-01—DB-11-03。此次已实际调取并视觉核对八张LOCK V2母图、四龙R2板、老君/白鹤R2板及相关场景、金龙候选；八位母图SHA-256均与锁版清单一致。此文是提示词与分镜预检修订，不是新图片的G4通过证明。

## 一、脚本版本与此次纠错

- 原剧本V3.0的S10为“八仙大显神通”、S11为“玄溟终战”；本批DB-10、DB-11来自后续《12节72关键帧执行表V3.3》的龙族大战扩展线，分别为“合体金龙”“八宝镇墟”。两套编号不可互换；本次精修沿用上轮明确的这十张DB镜号，不宣称已补齐原稿或核清全库缺图。
- 旧稿硬写“冷色主光”与母图不符：八人母图为青灰风暴环境光叠加上右暖金天光。改成沿批准参考保留主光方向与冷暖关系，不凭图片编精确色温数值。
- 四龙R2明确是四条无翼中国龙；合体金龙是另一个资产。已找到金龙图片，但“已有文件”不等于“已定型通过”。现有候选一张偏直立厚重四足、一张偏修长盘旋，不能把二者身体、龙首、翅膀混搭。
- 何仙姑的“手持莲花”与“承重巨莲台”是两个独立部件。旧关键词“巨莲直接变成法器基座”可能令她突然失去支撑，已删除；DB-11-02仅提出以手持莲花承担中心基座功能的设计候选，实体尺寸和装配结构仍需定型，不能自动放大。
- “八宝”指八位角色的法器套组，非八个物件。葫芦不是两只，鱼鼓为一筒两杆，玉板为一白一青两块；铁拐、拂尘、背鞘、白驴及莲台不随核心法宝一并消失。
- 第9节蓝采和拍板只在用户指定的趣味插入图出现，不据此给全片母图新增永久法器，不投入八宝组合。
- 阵位、相机、法器转交路径未锁时只能写为“本轮建议”，不能把建议站位冒充原定图。已有获批图不覆盖、不重绘。

## 三、每条请求的公共前缀

参考图受控编辑，一次一张独立电影静帧；9:16满幅真实竖构图，禁止分屏和故事板。仿古真人史诗电影质感、国风CG与真实材质融合；真实肤质、湿润织物的重量、金属粗糙度、石面水膜与雨滴尺度清楚。保留输入母图的脸、发式、体型、衣层与法器形制，改变动作不重设演员。上右暖金破云光为方向基准，青灰天海环境光补暗，法术光只形成有来源的局部反射，不能冲掉原主光阴影。云海、雾层与浪面有前中后层级，视觉中心明确、暗部可读、高光柔和，不靠强锐化和泛光冒充细节。

镜号与参数只写在任务记录，不印在画面上。正式目标2160×3840 PNG；原生尺寸、放大尺寸分别记录，“8K观感/UE5质感”不是像素或引擎证明。母图只读，生成前实际挂载对应原图；候选生成后还需核图，不声称逐像素不变。

空间：近岸八仙在左侧、外海来敌在右侧为跨镜主轴。具体机位中的屏幕位置仍须按场景卡登记；反打用中性过渡，不机械把每个人固定在同一屏幕位置。村庄、礁路与海堤采用同一批准背景，未建立的背面地形不自由补造。风向以本场前一批准帧为准，不从所有来源图硬推一个未经测量的全片风向。

### 02｜DB-10-02 四龙向同一中心汇聚

**原脚本事件：** 四龙向同一中心汇聚，四条轨迹仍可追踪。

### 03｜DB-10-03 水雾金光遮接融合瞬间

**原脚本事件：** 融合控制瞬间以水雾与金光遮接，禁止多头乱肢。

**引用：** DB-10-02通过状态；四龙外缘轮廓；后继金龙轮廓仅在其结构批准后使用。

**正向正文：** 同一海面汇聚中心形成有层次的浓水雾，雾内金光由内向外透出，亮部不过曝，外围保留四条趋近中心的水汽轨迹与少量鳞色边缘作为来源证据。可见四龙部分允许正常被雾遮挡，不能在雾外长出混合龙头、断尾或额外翅膀。海面下方形成与中心相对应的局部涌浪，水滴、雾与反射都受同一法术中心影响；外围背景与固定礁位保持不变。主焦点是中心的轮廓变化接点，不描绘完整解剖融合过程。
