# 文字成图规则 V2.0

适用：单幅关键帧、人物/场景/道具概念图及套图。与[图生视频规则](image-to-video-rules.md)分开执行；分类词表和足部细则复用[穿帮防控规则](image-video-continuity-rules.md)，不重复堆入每个请求。

## 生成前锁定

| 字段 | 必须明确的内容 |
| --- | --- |
| 本镜任务 | 单张图的唯一时刻、用途、景别、画幅和允许裁切线；特写不强求全身 |
| 角色 | 本镜可见人数、身份、服饰/发型版本、姿态、视线与左右手；不得把全故事人物都画进来 |
| 道具 | 名称、数量、部件、比例、轴线、持握、支撑、连接与遮挡；参考用途分开标注 |
| 场景 | 场景ID、门内外、人物前进方向、固定锚点、天气/时段、光源与相邻镜状态 |
| 允许变化 | 神通、漂浮、变形、残肢、特殊造型按本次设定保留；未批准细节不能自行当作锁定事实 |
| 文字/风格 | 保留用户要求的宋韵/CG/动漫/写实等风格；需要的招牌、字序、横竖方向、品牌水印逐项锁定 |

参考图缺失的背面、底面和隐藏部件登记待确认。不得为了“结构完整”扩出未批准部件；复杂道具优先露出能自洽验证的区域。

## 提示词组成

主体与本镜动作时刻 → 明确构图 → 道具结构与接触 → 场景方位 → 光影材质 → 输出规格 → 相关负面约束。只画一个时刻，不把先后动作拼成多手、多脚或多物件。

通用正面模板：

> 按本镜批准参考绘制，保持用户指定身份、服饰、风格、文字与画幅；只出现本镜可见人物及指定数量道具。部件轴线、连接、握持、支撑与遮挡合理；每只鞋一组鞋面和鞋底，无衣摆下额外鞋形，特殊肢体依角色设定。建筑透视、纹理、光源与反射一致。神通按明确设定呈现。关键元素在要求的构图范围内，留足边缘空间。

负面词分“基础结构＋相关道具专项”，使用共享编译器；不无条件禁止漂浮、变形、文字、logo、动漫、局部裁切或正常光影变化。否定道具和未入镜道具不应触发新增专项要求；文本识别只作保守辅助，复杂否定句仍需人工检查。

## 接口执行

- `compile_prompt(stage="image")` 输出最终正文、负面词、规则版本与模式；只替换自身终端规则块，重复编排不堆叠。
- HF/fal/Cloudflare现有适配器没有启用独立负面字段，因此把约束写入实际正文；OVH使用独立字段并与计划一致；原生千帆图片同样编入实际正文，不臆造API字段。
- 长度限制按仓库适配器的既有防护检查，不当作全球平台最新规格。先检查最终正文，空间不够时精简规则，但保留原文、相关专项及负面词；仍超限则在调用前拒绝并要求精简任务或拆镜。
- dry-run与正式调用使用同一编排与预算检查。记录`rule_version`、`prompt_chars`和负面传递方式；未发送不能写“已发送”。
- 不把提示词中的8K、UE5、35mm等当作实际输出参数或实测证据。

## 静态验收

先看全图人数、空间、姿态、构图，再放大脸、双手、脚、道具接口和遮挡边缘；与批准母图、相邻批准镜头比对。足部逐个数鞋面、鞋底、鞋尖和鞋跟，检查衣摆下第三只鞋及重复鞋底。局部修复后全项回归，防止修脚换手、修剑换衣。

多余肢体/鞋、道具断接、轴线错位、穿体、人数或物件增殖为阻断；遮挡证据不足为待核查，不凭想象判通过。只有静态合格且所需参考明确，才进入视频制作；生成成功和文件可解码不等于视觉验收。
