# 多人战斗战场契约 V3.2｜G4-M / G5-M
2026-11-11 · 星火3.0与八仙大显神通增补 · 本文件为规则，不代表运行时已执行。

## 优先级
LOCK V2批准人物/法器母图及SHA > 批准分镜和状态 > 战场契约 > 美术提示词。严禁重新绘制已锁人物或法器。16:9八仙母版不变；2.35:1需额外审批。原文建议前中后排人数、妖魔曝光和法术面积是复杂度基线，不能强行修改八人同框的批准剧情。

## S2/G2 前必须签署七项战场不变量
1. period_costume_system：唯一时代/架空服制系统。
2. frame_camera_axis：批准画幅、镜头/机位/焦段、180度轴线。
3. physical_key_light：主导物理光位置/色温/强度；附加火光及法器神光记录来源与反射。
4. primary_secondary_ground：主/次地表、碰撞平面、湿度。
5. atmosphere_3_layers：近景雾、中景烟、远景霾与透射率。
6. wind_impact：统一风向、风速、冲击波时间，粒子和衣料响应。
7. faction_palette：阵营配色，禁止改动已定型BX服装颜色。

## 每人六字段位次卡
character_asset_id + locked_identity_anchor/master_sha256; artifact_asset_id + canonical_hand/grip; pose/facing/eyeline; depth_layer; occlusion_relation。补充上镜状态、承重、法宝状态和前镜衔接。身份锚文本绝不代替原图比对。

## 法宝及敌方
法宝 IDLE → ACTIVE → OVERLOAD，默认同帧最多2件过载、单件主要发光面积≤1/6，例外由镜头审批。接触点/力学/反光斑真实，不能复制、临时换手或悬空无因。妖魔材质必须有湿鳞、角质、骨裂等可信微结构，默认视觉亮度低于主体且不能产生克隆脸。巨怪尺寸、数量是推荐参数，不覆盖剧本。

## G4-M 静态硬门禁（逐镜15项 PASS/FAIL/NEEDS_EVIDENCE）
01手指关节 02法宝归属/手别/几何 03真实抓握 04阴影方向 05神性次光反射 06服制配色 07悬浮重心 08脚/驴蹄/莲台接触 09三层雾 10面部不被泛光吞没 11妖魔主次 12无重复人物 13无伪字水印 14风与粒子同向 15穿模/遮挡恢复。
必须同时满足G4与G4-S。FAIL或NEEDS_EVIDENCE不能放行；模型自称PASS无效。

## G5-M 动态门禁
首帧SHA、末帧SHA、前镜状态、主相机轴线、法宝激发事件、主光和神光时间曲线必填。检查整段视频及首中尾、动作转折、法术触发、遮挡恢复。G5-S/G5-M任一FAIL或证据缺失阻断下一工序。

## 八仙专属锁定
BX01铁拐李紫金葫芦/铁拐；BX02汉钟离绿色巨型扇；BX03吕洞宾背剑+拂尘；BX04蓝采和蓝青袍/花篮；BX05张果老白驴四肢驮具、鱼鼓双杆；BX06韩湘子紫袍紫玉横笛；BX07何仙姑莲花及完整莲台；BX08曹国舅独立白玉板和青玉板。
道具位置和持握手以母图及已批准镜头为准。需要不同视角必须用新批准多视图资产，否则标NEEDS_REFERENCE，不允许自由重绘。
