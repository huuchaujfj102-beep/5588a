# 《八仙·大显神通》R6 20章连续性审计矩阵
日期：2026-11-21
基线：R5《01_20章融合升级案本.md》、R5《Baxian_Action_Beat_Storyboard.html》、140任务映射、137接续执行表
状态：文本审计第一轮；不是最终剧本锁定，不代表视频动态验收。

## 一、审计结论

R5已经建立了相对清晰的主因果：归墟裂隙/黑潮扩张→八仙救援→四王误封海→冲突升级→八仙初败→协同反攻→四龙合体反噬→老君指出阵眼→八宝争取归印窗口→沧汐归印→四王认错→人间收尾。这个主链可以保留。

但目前还不能称为“100分钟电影连续剧本”，也不能直接批量生成40段成片。主要阻断项：
1. **片长与叙事容量不匹配**：R5动作分镜表合计15:51（951秒），距100分钟少84:09；不能用慢放、静帧延长或重复斗法填充。
2. **剧情文本与分镜/素材并非一一对应**：R5文本写了完整动作过程，但部分静帧只是结果姿态；例如四龙合体、八仙落海、法器离主/归主、沧汐归印，必须有动作过程镜头或明确剪辑桥。
3. **若干章节只有“结果”，缺少选择过程和代价**：第8章四王为何不核验船只、第13章败退如何形成新策略、第17章收雾后为何触发四龙合体、第19章八宝如何同时约束金龙和封闭玄溟，均须在剧本和镜头中补足可见因果。
4. **第20章沧汐回到村口的物理路径缺失**：归印发生在海底旧槽，结尾却直接在阿宁门边；必须增加离开旧殿、被救/自行上岸、时间经过的交代，不能瞬移。
5. **连续性状态需要逐镜锁定**：同一人物湿衣、伤势、法器在手/离主/归主、四龙数量与形态、金龙唯一性、八仙落水后位置，都不能只靠章节说明。

## 三、全片因果链锁定（R6修订版）

1. 旧封印长期承压出现裂隙；黑潮从裂隙外泄，玄溟借水势和幻象扩大灾情。
2. 八仙到场的首要任务是救人；第4章攻击只打开局部潮甲，第5章证明辨路不等于破潮。
3. 沧汐在第6—7章识别守海印机制，但现实归印尚未发生；唯一方印始终在她手中，旧槽始终空。
4. 四王为阻止黑潮越界而封海；太子擅自扩大执行范围，四王看到伤者却默许，误判责任成立。
5. 四王化龙是因封海柱受黑潮反冲；四龙喷火与太子冲锋造成第一次战败。
6. 第14—15章把第一次败退转成“救援优先、协同破外围锁”的新策略；第16章只断外围一个节点。
7. 第17章收雾收兵后，四王发现黑潮回吸龙息；他们主动合力堵眼，才触发第18章合体。
8. 黑潮反控四王合体力量，唯一金龙翼展压海；八仙与白驴落水后逐人脱险。
9. 老君在全员脱险后到场，只指出“金龙潮势与阵眼相连”，不替八仙解决。
10. 第19章八宝阵锁牵引、标定阵眼；老君符锁争取时间；沧汐主动归印切断裂隙支点；玄溟内坍、金龙解体。
11. 四王目睹八仙救海族伤兵与民众后认错，解除海禁；八宝此后才归还。
12. 第20章用可见的归岸过程、修堤、点灯和沧汐记忆余韵收尾。

## 四、全片人物/道具/形态连续性硬锁

- 八仙八人全片人数固定；不得重复生成、漏人、换位瞬移。
- 法器按原主锁定：铁拐李铁拐+唯一双肚单顶口葫芦；汉钟离唯一巨绿芭蕉扇；吕洞宾白拂尘+唯一银剑（剑在背鞘/手持/阵中/归鞘状态必须登记）；蓝采和唯一花篮及原拍板；张果老一筒鱼鼓双棒+同一白驴；韩湘子同一紫玉横笛；何仙姑小莲与巨莲台用途分开；曹国舅白青双玉板为一套。
- 沧汐唯一方印：第6—7章手持，第19章入唯一旧槽，此后不再回手；唯一原发簪始终在位。
- 四王人形→四条青赤白黑无翼龙→唯一巨大四足双膜翼金龙→四王归位。禁止第五条实体龙、重复小金龙、提前长翼、龙体同时保留四条完整龙形。
- 金龙压海后，八仙衣物湿透、体力受损；脱险后不得瞬间干衣、恢复定妆照状态。
- 老君第18章末才出现；不得在第15、16章提前指导战术。
- 八宝阵只计八套法器；铁拐、白拂尘、巨莲台、白驴不作为额外阵节点。
- 八宝离主必须先有原主人手/腰空出、法器沿可追踪路径入阵；认败前不得提前归主；归还后不得保留阵中副本。

## 五、片长与结构整改原则

R5预剪15:51只是现有分镜的预剪总长，不是100分钟长片。R6不能将现有40段强行拉长到100分钟。应先把20章升级为真正的长片剧本：增加有因果的救援支线、四王/太子决策链、八仙内部协作与代价、沧汐选择过程、战后修复与人物余韵；每场新增内容必须改变人物关系、局势、信息或代价。不得增加无因果的重复斗法、纯空镜、无意义慢动作。

建议把100分钟目标拆为五幕（暂定配额，不是锁定时长）：
- 第一幕 0–20分钟：渔村、封印裂隙、八仙救援、辨幻规则、沧汐出现。
- 第二幕 20–40分钟：守海印代价、四王封海、太子误判、龙族列阵与第一次冲突。
- 第三幕 40–62分钟：四王化龙、龙宫冲锋、第一次败退、高岩救援与内部争执。
- 第四幕 62–82分钟：协同反攻、外围潮锁受阻/破解、收雾收兵、四王合体与金龙翻海。
- 第五幕 82–100分钟：八仙脱险、老君指阵眼、八宝镇归墟、沧汐归印、四王认错、归还法器、村庄收尾。
时长最终必须由完整场次与对白/动作表演计算，不用平均分章。
